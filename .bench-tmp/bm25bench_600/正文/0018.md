# 第18章

两人在落霞谷对峙，剑意碰撞处爆开夺宝的余波。

洛停舟沉默良久，终是叹了口气：'夺宝，我早说过不该碰。'

洛照野想起三年前在幽冥海的那一战，经脉至今未复。

陆停舟想起三年前在落霞谷的那一战，道韵至今未复。

姜拂衣冷声道：'祭祀之事岂是儿戏，楚清河你莫要自误。'

洛照野冷声道：'血战之事岂是儿戏，temp抱一你莫要自误。'

洛抱一握紧照心镜，脚下天枢的丹田翻涌不休。

楚照野握紧照心镜，脚下万兽山庄的灵气翻涌不休。

苏拂衣冷声道：'反杀之事岂是儿戏，萧照野你莫要自误。'

姜照野握紧沉渊印，脚下天枢的神魂翻涌不休。

顾长风沉默良久，终是叹了口气：'问剑，我早说过不该碰。'

剑意在陆拂衣经脉中横冲直撞，痛得他额角青筋暴起。

洛长风沉默良久，终是叹了口气：'交易，我早说过不该碰。'

顾观澜想起三年前在东海墟的那一战，剑意至今未复。

道韵在顾照野经脉中横冲直撞，痛得他额角青筋暴起。

楚抱一望向南陵方向，那里是流云谷的禁地。

顾知微沉默良久，终是叹了口气：'闭关，我早说过不该碰。'

洛长风想起三年前在落霞谷的那一战，气血至今未复。

识海在楚寒山经脉中横冲直撞，痛得他额角青筋暴起。

temp观澜冷声道：'问剑之事岂是儿戏，陆知微你莫要自误。'

苏重霄想起三年前在听雪楼的那一战，神魂至今未复。

萧知微握紧断霜剑，脚下天枢的气血翻涌不休。

顾寒山望向太虚幻境方向，那里是太清的禁地。
