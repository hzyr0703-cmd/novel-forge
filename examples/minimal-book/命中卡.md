# 15维爆款命中率卡（示例）

> 这是 **样例**，不是对你项目的评分。用途：照着这个格式写自己项目的命中卡。
> 校验方式：`python forge.py hitrate --file 命中卡.md`，退出码非 0 即禁止动笔。
>
> 硬纪律（机器复核）：
> 1. 每维必须给理由，理由要指向具体设定或文本，不许写「感觉不错」
> 2. 单维满分 ≤ 3 项（超过即判虚高，须下调或声明修正分）
> 3. 否决项 D4（开局冲突）、D12（AI 味）任一为 0，总分再高也不得开工
> 4. 天花板项 D1/D11/D13 任一 ≤ 2，总分上限锁 74
