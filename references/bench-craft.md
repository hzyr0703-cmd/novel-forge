# 对标库手法池（防模板版）

> 定位：v3.2 新增、v3.3 补开篇层（D 层）、v3.4 补卷尾层（E 层）、v3.5 补反派与对抗层
> （F 层）卡。来自五本头部对标书（《我不是戏神》《我在精神病院学斩神》
> 《诡秘之主》《宿命之环》《十日终焉》）语义层拆解——即 `book-teardown.md`
> 七步产物（概要/角色/剧情/设定/金手指/爽点抽样/文笔风格）——中**被验证过**
> 的结构与文笔手法，蒸馏成「选择项池」。
>
> 它不是流程、不是检查清单、不是句式库。`chinese-prose-craft.md` 管笔力本体、
> `human-texture.md` 管人味、`scene-architecture.md` 管场景骨架——与它们冲突时
> 一律以那三份为准。本文件只做一件事：写不下去、需要一件被头部书验证过的工具时，
> 多一个选项。

## 一、防模板纪律（先读这个，再看手法）

1. **手法是菜单，不是工序**。动笔前先回答「这一章的读者情绪任务是什么」，
   再看池子里有没有一件工具恰好服务它；没有就直写。禁止逐项核对「这章用了几个
   手法」——手法被指标化就会触发 P18（门禁越严正文越像 AI，见 `pitfalls.md`）。
2. **冷却制**：同一张结构卡（A 层）5 章内不复用，章级卡（B 层）3 章内不复用。
   开篇卡（D 层）一次性使用（每本书/卷的开篇只做一次），卷尾卡（E 层）同样一次性
   使用（每卷的高潮段只做一次）；反派层（F 层）卷级设计卡（F1–F5/F8）用于卷纲与
   细纲各设计一次，章级卡（F6/F7/F9/F10）按 B 层 3 章冷却，同变体连用两次同样按
   复读处理。
   `check-cross-diversity.py` 只查开头/结尾/爽点类型的同型，手法同型靠自检。
   同一**变体**连用两次，按复读处理。
3. **变体制**：每张卡带 2–3 个变体。命中触发条件 ≠ 照第一个变体执行——
   先看本章人物、场景、信息差与哪个变体贴合，选完允许再改造。
4. **拆结构不拆句子**：对标书句式只允许抽象成机制后重写，不允许保留原句骨架
   换词。这同时是版权纪律（`book-teardown.md` 文件头）与 AI 指纹纪律
   （整句移植对标句式，是另一种模板腔）。
5. **让位规则**：与项目追踪台账、用户当轮约束、本章细纲冲突时，一律让位。
   手法池是「多一个选项」，不是「多一个必须」。

## 二、消费流程（按需读，不全读）

书目录 `对标/<书名>/` 下：

| 要决定什么 | 读什么 |
| --- | --- |
| 卷级结构 / 势能台阶 | `概要.md` + `金手指.md` |
| 本章事件排布 / 爽点间隔 | `爽点抽样.md` |
| 落笔句感 | `文笔风格.md`（第 7 节是可迁移清单） |
| 新书/新卷开篇细纲 | 各书 `开篇.md`（第 1–10 章拆解）+ 本文 D 层卡 |
| 卷尾/高潮段细纲 | 各书 `卷尾.md`（卷尾逐章功能表拆解）+ 本文 E 层卡 |
| 反派/对抗戏细纲 | 各书 `反派.md`（反派阶梯与轮换拆解）+ 本文 F 层卡 |

日常章不必翻库。卡文、写卷首卷尾、写大爽点章、做卷纲、做开篇细纲时才翻。

## 三、手法池

### A 结构层（卷/弧级，低频；全书用量级 ≤ 卷数 × 2）

**A1 金手指生存契约**（出处：`对标/我不是戏神/金手指.md`、`对标/十日终焉/金手指.md`）
- 触发：金手指设定评审、升级节点设计。
- 机制：能力每次兑现都挂数值化代价或死线（期待值 <20% 即死 / 死亡即学费），
  爽点因付费而可信。
- 变体：a 死线挂稀有资源；b 死线挂人格/记忆损耗；c 死线挂身份暴露风险。
- 忌：死线常悬不落（狼来了）；每章都扣代价，爽文写成苦修文。

**A2 马甲经济学**（出处：`对标/我不是戏神/金手指.md`）
- 触发：设计主角信息层 / 身份层时。
- 机制：每层身份 = 一个爽点发生器 + 一根掉马引信；掉马时机按「读者早知道、
  场内人不知道」的信息差排。
- 变体：a 身份互为掩护；b 身份互相冲突（左手打右手）；c 身份被第三方冒用。
- 忌：马甲超过 3 层读者记不住；掉马零代价。

**A3 断点章**（出处：`对标/十日终焉/概要.md`）
- 触发：每 80–100 章的卷中部疲劳点。
- 机制：整章清账——集中翻底牌、回收悬置，把匀速悬念改成闸门式释放。
- 变体：a 自述型；b 对峙摊牌型；c 旁观者复盘型。
- 忌：连续两卷同一断点章型；断点章之后没有新债。

**A4 章型配对还债**（出处：`对标/我在精神病院学斩神/剧情/故事线.md`）
- 触发：还伏笔 / 情感债时。
- 机制：债的类型决定偿还章型——情感债用仪式/重逢章、谜题债用回溯章、
  规则债用回环章（意象首尾同现）。
- 变体：即机制中三型，可混合（一场重逢同时回环一个意象）。
- 忌：所有债都用解释性对白还。

**A5 卷尾「收 = 新问题」**（出处：`对标/十日终焉/概要.md`、`对标/诡秘之主/概要.md`）
- 触发：卷尾细纲。
- 机制：卷尾不解散压力，把已解规则升维成新问题（逃出十日 → 现实也在轮回）。
- 变体：a 老答案引出新问题；b 新视角重看旧事实；c 收掉一条线的同时另一条升一档。
- 忌：为钩而钩——新问题必须在既有设定里有根。

### B 章级（中频）

**B1 倒计时节拍器**（出处：`对标/我在精神病院学斩神/金手指.md`）
- 触发：回报需要跨章拖延时。
- 机制：可视化进度（进度条 / 搜索逼近 / 倒数），读者随时知道回报多远——
  拖延而不失耐心。
- 变体：a 敌方进度条；b 我方充能条；c 双条赛跑。
- 忌：一卷内连用；进度造假（说 85% 却三章不动）。

**B2 白嫖 + 身份倒置**（出处：`对标/我在精神病院学斩神/金手指.md`；与白嫖强者流同构）
- 触发：收服 / 借力桥段。
- 机制：收服条件数值化（可量化门槛），得手后身份倒置（强者变打工人），
  威严与反差双吃。
- 变体：a 倒置带隐情（假意臣服）；b 倒置带职责（按契约干活）；c 倒置带成长（效忠度可变）。
- 忌：反复倒置同一个人的威严——反差会通胀。

**B3 先立威后报价**（出处：`对标/宿命之环/金手指.md`）
- 触发：谈判 / 收编 / 交易场。
- 机制：冷酷展示 → 恐怖确认 → 反转收账（「恭喜你通过考验」式），威慑先行、
  条件后置。
- 变体：a 报价收人；b 报价收情报；c 报价收时间（拖延敌人）。
- 忌：每次谈判同款三段；对方无理由配合。

**B4 预埋—引爆暗手**（出处：`对标/宿命之环/金手指.md`）
- 触发：主角不能亲自出手的局。
- 机制：提前 2–3 章埋无关注意项（一句话 / 后门 / 心理暗示），当章引爆 + 两行内
  复盘自解释——爽感来自「原来早埋了」。
- 变体：a 借敌之手；b 借规则之手；c 借队友之口。
- 忌：预埋不进伏笔台账（会撞 `check-factconflicts.py`）；复盘超两行。

**B5 群像测温扬名**（出处：`对标/诡秘之主/概要.md`、`爽点抽样.md`）
- 触发：扬名 / 威慑需要呈现「量级」时。
- 机制：不写主角写旁观者，反应链测出量级（围观 → 业内 → 顶层三镜头）。
- 变体：a 三镜头递进；b 单镜头留白（只写最高层反应）；c 反向测温（敌人慌了）。
- 忌：与 `human-reaction.md` 群体分裂原则冲突的「全场一致」反应链。

### C 句级（高频；必须混用，单项不连章）

**C1 对话末句炸弹**（出处：`对标/十日终焉/爽点抽样.md`、`文笔风格.md`）
- 触发：高对话章的爽点引爆位。
- 机制：揭晓句放对话最后一句、短句收；前文对话全是铺垫。
- 变体：a 自认式；b 点破式；c 沉默式（动作代替揭晓句）。
- 忌：连续章节都用对话揭晓；揭晓句配感叹号 + 排比。

**C2 画面定格 + 半句掀前提**（出处：`对标/诡秘之主/文笔风格.md`）
- 触发：章末钩选择。
- 机制：先给完整安定画面，最后一句改变画面性质——比悬念省略号省字且不装。
- 变体：a 定格物证；b 定格反常动作；c 定格时间错位。
- 忌：每章同用；钩子与本章内容无关的硬切。

**C3 仪式感升级四步**（出处：`对标/诡秘之主/金手指.md`）
- 触发：借力 / 收服 / 升级的呈现章。
- 机制：异象 → 能力清单 → 身份自答 → 他人反应链，给力量获取「受洗级」重量，
  防白嫖贬值。
- 变体：a 完整四步（大节）；b 砍清单留异象 + 反应（中节）；c 倒叙（先反应后异象）。
- 忌：每次小借力都全套——重量感来自稀缺。

**C4 短句连击与留白**（出处：`对标/十日终焉/文笔风格.md`、`对标/我不是戏神/文笔风格.md`）
- 触发：紧张 / 恐怖 / 战斗段。
- 机制：紧张段把叙述句压到最短（主谓宾），威胁不写满；数字具象威胁
  （先给数字后炸真相）；战斗按场面选一招一段或连招流水。
- 变体：a 短句连击 + 单行长句呼吸；b 数字具象威胁；c 规则文本半遮。
- 忌：全章短句（单调）；留白过度（读者看不懂发生了什么）。

**C5 环境写心理**（出处：`对标/诡秘之主/文笔风格.md`、`对标/宿命之环/文笔风格.md`）
- 触发：情绪戏需要镜头退半步时。
- 机制：不写「他很难过」，写环境里与他状态共振的一两个物件，环境承担心理职能。
- 变体：a 物件异化（熟悉物陌生化）；b 环境节奏同构；c 环境反差（大喜写冷景）。
- 忌：环境描写连超 3 行（拖番茄节奏）；与 `narrative-distance.md` 过滤器动词
  冲突的「他看见……」句式。

## D 开篇层（新书/新卷第 1–3 章细纲时才读；一次性使用）

五本对标书前 10 章精读拆解（各书 `开篇.md`）验证过的开篇机制。开篇只写一次，
不存在跨章冷却，但变体制与让位规则照常生效。

**D1 先卖奇观，后卖人**（出处：`对标/我在精神病院学斩神/开篇.md`）
- 触发：第一章第一印象设计。
- 机制：首镜头给一个违背常识的反常画面当钩子，围观者/旁观对话充当世界观解说轨，
  主角名字压到全章后 1/3 才出现——读者先记住「事不对劲」，再认识人。
- 变体：a 街头奇观+围观者；b 事件现场+在场者只言片语；c 异常内部+受影响者视角。
- 忌：连续多章只有奇观不引入人物；奇观与主线无关（纯怪味钓饵）。

**D2 金手指错位亮相**（出处：`对标/诡秘之主/开篇.md`、`对标/十日终焉/开篇.md`）
- 触发：决定金手指在开篇的亮相场景。
- 机制：亮相时动机与结果错位（为回家重做仪式→反被拉入灰雾）；第一用法是
  求生/还债而非变强——欲望与代价先行，爽点后置。
- 变体：a 仪式偏离本意；b 找出口走进谜里；c 被动卷入后靠观察发现能力。
- 忌：要什么给什么；亮相即讲完规则；用亮相场景直接装逼。

**D3 金手指三段解锁**（出处：`对标/我在精神病院学斩神/开篇.md`、`对标/宿命之环/开篇.md`）
- 触发：多阶段能力系统的开篇节奏设计。
- 机制：谜面（只给来源悬念）→ 带进度条的过渡态（读者随时知道离完全体多远）→
  危机+情绪引爆完全体；解锁后立刻兑现一个爽点、同章结清代价。
- 变体：a 线性进度条；b 碎片收集式；c 只在危机中解锁。
- 忌：规则一次放完；进度条不可见（读者不知道还差多少）；完全体无代价。

**D4 强中弱钩交替 + 功能性弱钩章**（出处：`对标/诡秘之主/开篇.md`）
- 触发：开篇 3–10 章的章末钩序列编排。
- 机制：强/中/弱钩刻意交替（实测：第 1 章强钩立悬念，第 3 章即可放弱钩喘息）；
  弱钩章不许空转——一章内完成次要人物立像、经济规则、势力名单、新小悬念四件事。
- 变体：a 情绪弱钩；b 喘息弱钩；c 假弱真暗钩（表面收小、暗埋大线）。
- 忌：弱钩放在第 1 章；弱钩章没有任何悬念线在跑。

**D5 章末钩双轨管理**（出处：`对标/我在精神病院学斩神/开篇.md`、`对标/宿命之环/开篇.md`）
- 触发：开篇连续跑的节奏管理。
- 机制：日常章收仪式钩/信息差钩，冒险章收危机钩；危机钩最多三连，随后必须
  温情/幽默泄压一章；本章章末钩即下章首景，无缝咬合。
- 变体：a 三连危机+幽默泄压；b 仪式钩循环（每晚敲门式固定动作）；c 情感钩泄压。
- 忌：危机钩四连；章末钩与下章内容无关的硬切钩。

**D6 悬念快慢分层**（出处：`对标/我在精神病院学斩神/开篇.md`、`对标/诡秘之主/开篇.md`、`对标/十日终焉/开篇.md`）
- 触发：开篇的悬念预算分配。
- 机制：母悬念（世界观级）开篇 10 章内只加深不兑付；微悬念 8 章内兑现第一笔。
  每条悬念线带偿还间隔上限（实测：诡秘埋→兑 ≤5 章、斩神微线 8 章、十日规则线 7 章）。
- 变体：a 单母悬念+多微线并行；b 母悬念嵌套（每解一层露出更大一层）。
- 忌：母悬念提前兑付；微悬念拖过上限又没有加码续期。

**D7 故事中的故事埋真设定**（出处：`对标/宿命之环/开篇.md`）
- 触发：世界观需要低成本曝光、又不想开篇大段设定时。
- 机制：开篇借某人之口讲一个「故事」（自白/传闻/民间怪谈），中段拆穿为虚构——
  但故事里的关键细节全是真设定，后续逐一应验，形成二次回收爽感。
- 变体：a 第一人称自白；b 世界内文本（日记/案卷）；c 第三者转述。
- 忌：拆穿后不回收（故事细节无人应验）；故事太长不拆穿（读者当真设定记错账）。

**D8 反转量级只升 + 底牌预算**（出处：`对标/我不是戏神/开篇.md`）
- 触发：开篇期反转的量级编排。
- 机制：反转量级只升不降（异常→搜捕→杀主角级），每 2–3 章一记；杀主角级反转
  必须提前预算底牌（保命物/未知能力/第三方介入）且前文有来处；爆发后立刻引入
  更强者重新校准天花板——爽而不崩。
- 变体：a 假死复活；b 制度性救援（征召令把主角推上主舞台）；c 强敌反成转机。
- 忌：无底牌硬杀主角；反转不推进主线；爆发后不校准天花板（后续危机失去重量）。

### 开篇层节奏标尺（五本实测）

| 书 | 金手指亮相 | 第一个爽点 | 章末钩主形态 |
| --- | --- | --- | --- |
| 诡秘之主 | 第 5 章（意外触发） | 第 6–7 章（信息差装逼） | 强中弱交替 |
| 斩神 | 第 1 章谜面→第 3 章过渡态→第 8 章完全体 | 第 9–10 章 | 双轨+三连上限+咬合 |
| 十日终焉 | 第 1 章（数字矛盾观察） | 第 8–10 章（揭示型） | 信息差主力、不换谜面只加码 |
| 我不是戏神 | 第 1–2 章（压力器规则） | 第 6 章 | 量级只升、每 2–3 章一记 |
| 宿命之环 | 第 5–6 章（凭证先行） | 第 10 章 | 信息差/危机交替+咬合 |

- 参考线：金手指亮相不晚于第 5 章；第一个爽点不晚于第 10 章；开篇 10 章内
  母悬念不兑付、微悬念至少兑现一笔。

### E 卷尾层（卷尾/高潮段细纲时才读；每卷一次性使用）

五本对标书卷一卷尾精读拆解（各书 `卷尾.md`）验证过的卷尾机制。卷尾收束规则归
A5「收 = 新问题」管（五书实测三种落地：同现场三连钩 / 老答案派生清单 / 零间隔开新账），
本层不重复；升级呈现归 C3 管法照旧。E 层每卷只用一次，变体制与让位规则照常生效。

**E1 蓄爆韵三段配速**（出处：各书 `卷尾.md` 卷尾逐章功能表）
- 触发：卷尾段细纲排章。
- 机制：卷尾 = 蓄能段 → 爆发段 → 余韵段，三段都要成段，禁止爆完即完；
  蓄能章逐章升压（结算→被困→自救失败→仪式/决战启动），蓄能期内不许插无关支线。
- 变体：a 均衡型 4:1:4（诡秘）；b 战斗浓型 3:3:2（斩神）；c 长蓄型 9:2:3（戏神）。
- 忌：爆发只有一章且蓄能不足 3 章（爆点失重）；余韵段零章直接进下一卷。

**E2 爆发章卖惨、余韵章还爽**（出处：`对标/诡秘之主/卷尾.md` 0209–0211）
- 触发：大爆点不够能量时。
- 机制：爆发章以惨烈收（胜利+牺牲+主角重创），真爆点延迟 1–2 章在余韵段兑付
  （坟中复活）——延迟本身构成二次蓄能，读者带着「不可能就这么完了」翻章。
- 变体：a 复活式延迟兑爽；b 揭底式延迟兑爽（下一章才解释这一章的反常）；
  c 反转式延迟兑爽。
- 忌：延迟兑现无预埋（读者只觉得断章）；延迟超 3 章（蓄能变烂尾）。

**E3 双声部引爆**（出处：`对标/我在精神病院学斩神/卷尾.md` 26–28）
- 触发：单爆发点撑不起卷尾时。
- 机制：配角牺牲式爆发先响（觉醒/赴死），主角底牌爆发接爆，两个峰值间隔 ≤1.5 章；
  爆发章节拍固定——拒绝救援→绝望确认→道具插叙来历→临终独白→爆发→先给结果
  画面→末行才报名。
- 变体：a 前峰配角、后峰主角；b 前峰敌人、后峰反杀；c 前峰明线、后峰暗线。
- 忌：双峰熔成一章（没有呼吸）；配角之死不为后峰充能（白死）。

**E4 断点段式信息爆发**（出处：`对标/十日终焉/卷尾.md` 079–088）
- 触发：卷尾不宜再打一场大仗时（战力已透支 / 主打悬疑）。
- 机制：零战斗，信息当量代替动作当量——断点段三层剥洋葱（翻行为→翻动机→翻
  闭环），每章末钩指向更黑一层；闪回终点精确回环正文开篇场景（首句复用）；
  前后两波爆发分离（动作高潮在前，信息爆发在后）。
- 变体：a 单人 POV 三连闪回；b 多视角拼图；c 对峙中逐层摊牌。
- 忌：洗白式翻底牌（黑幕翻完变温情）；回环只做姿态不给新拼图。

**E5 世界翻面式总爆**（出处：`对标/宿命之环/卷尾.md` 0104–0109）
- 触发：卷冲突是认知级（真假/梦境/身份）而非胜负级时。
- 机制：不打赢强敌，让整个舞台翻面——仪式被外力干扰+记忆被强制拖出双钥匙
  同时拧动，整卷前提被宣布为假；需双证据链闭环（证据要提前 2–4 章预埋）；
  温情点垫在惨剧前（先给暖再砸碎）。
- 变体：a 梦境翻面；b 身份翻面；c 阵营翻面（自以为的盟友是局的设计者）。
- 忌：只给设定不给情绪出口（翻面后无人物反应链）；翻面无预埋证据（空降）。

**E6 三线合一引爆 + 按下即离场**（出处：`对标/我不是戏神/卷尾.md` 313–319）
- 触发：多线在卷尾汇流时。
- 机制：晋升+救赎+身份穿帮等 2–3 条线叠在同一按钮上一次引爆；引爆瞬间主角
  即离场（失能/离城/昏迷），切群像平行剪辑收余波；后续用非人化返场二次引爆
  （以传闻/异象形态回归）。
- 变体：a 主角消失式离场；b 主角失能式离场；c 主角被封赏/收编式离场。
- 忌：离场靠临时新能力（无来处）；群像剪辑每线超 800 字不切。

**E7 代价结算改写下一卷资源格局**（出处：`对标/诡秘之主/卷尾.md` 0212–0213、`对标/宿命之环/卷尾.md` 0109）
- 触发：卷尾代价设计。
- 机制：代价不给「当场能补偿的小亏」，而是改写下一卷的起点（社会身份清零/
  队伍降级/背上死线诅咒）；反派或对手同步升一档，保张力对等；代价结算里藏
  下一卷的入场券。
- 变体：a 身份清零重启；b 资源换成更差但更自由的位置；c 代价换关键人脉/情报。
- 忌：代价当天补偿（白疼一场）；代价与下一卷资源无关（疼完照旧）。

**E8 余韵形态菜单**（出处：各书 `卷尾.md` 余韵处理节）
- 触发：爆发后 1–4 章的余韵段排章。
- 机制：余韵必有形态，不写纯喘息章——五书实测五种：三明治喘息（家人视角→
  静默白描→组织接入日常，喘息不过夜）/ 冷文书+暖告别（冷热两层各一章）/
  延迟爽点（见 E2）/ 平行清账（每线一拍 300–800 字即切，主角缺席或失能）/
  借他人视角重新定价主角。
- 变体：即五种形态，可混合两层（先冷文书后暖告别）。
- 忌：余韵章无任何信息或情绪增量（纯旅游）；余韵超 5 章（泄压过度）。

**E9 矛盾式晋升条件前置 + 卷尾语义反转兑现**（出处：`对标/我不是戏神/卷尾.md` 304/305→316）
- 触发：升级/晋升节点落在卷尾时。
- 机制：晋升条件写成矛盾修辞（「无人问津的舞台×掌声鸣动的落幕」），卷中前段
  抛出挂账，卷尾借场景语义反转自然兑现——条件里的两个词在爆发场景里同时成真。
- 变体：a 条件两词各自对应一条线；b 条件在兑现时被主角重新定义；c 条件兑现
  带一个字面外的代价。
- 忌：台词宣讲「我终于满足了条件」；条件兑现与场景无关（凑数式达标）。

### F 反派与对抗层（写反派登场/交接/BOSS 战的卷纲与细纲时才读）

五本对标书卷一反派序列精读拆解（各书 `反派.md`）验证过的对抗机制。反派阶梯与
轮换周期属卷纲级设计，章级机制（单盲/保温/预案）落细纲。冷却口径见纪律第 2 条。

**F1 反派阶梯分级**（出处：各书 `反派.md` 反派阶梯节）
- 触发：卷纲设计反派序列。
- 机制：阶梯只升不降，每级解锁一个新对抗维度（新能力/新规则/新势力）；
  轮换周期按节奏选档——快节奏 7–8 章一换、中 13–14、长弧 22–30。
- 变体：a 兽形→兽形+异能→组织（斩神）；b 人性恶→体制→制度神格（戏神）；
  c 执行层→代理层→幕后信仰→幕后本体四层棋盘（宿环）。
- 忌：同级威胁连打三场以上；低级反派反复复活撑场。

**F2 压迫源交接三式**（出处：`对标/我在精神病院学斩神/反派.md`、`对标/我不是戏神/反派.md`、`对标/诡秘之主/反派.md`）
- 触发：旧反派退场、新压迫登场的设计。
- 机制：①同章交接——旧敌未肃清，新敌以战报/证据同章宣布登场（附战损证明交接
  可信）；②遗产长新敌——旧反派必留遗产（遗物/引信/气息），下一弧压迫源从遗产
  里长出来；③级联交接——前战代价成为后战失利的因果前环，退场章引流（死讯与新
  委托同章）。
- 变体：即三式，可两式并用（遗产+级联）。
- 忌：打完旧的空窗几章等新敌；新敌与旧线无关的空降。

**F3 压迫源叠加不替换**（出处：`对标/十日终焉/反派.md`、`对标/宿命之环/反派.md`）
- 触发：悬念型/规则型压力设计。
- 机制：旧压迫以未解决态封存（降频不退场），新压迫从旧奖励里长出来
  （赢一局 = 得资源 + 添新麻烦）；压迫感靠情报链收网逐环加压，不靠换敌。
- 变体：a 规则机器+可换零件（人物反派全是规则的执法位）；b 情报链逐环收紧。
- 忌：压迫源清零式收尾；新压迫与旧战利品无关。

**F4 零降智三机制**（出处：`对标/我不是戏神/反派.md`、`对标/诡秘之主/反派.md`、`对标/宿命之环/反派.md`）
- 触发：写反派决策与失误前。
- 机制：①决策基于可见信息+组织规则（任务手册/法庭程序/经济理性），反派不自知
  的信息不进决策；②失误由机制制造（强制激怒能力/异化失控）且失误即注解——用
  一句「符合他当时的状态和隐含的逻辑」收口；③行为逻辑推理文替作者盖章（借书中
  聪明角色分析反派动机）。
- 变体：a 十日式「职务行为泄漏」（反派败于自己职务动作露出的破绽）；
  b 疯狂中的自尊逻辑（疯但有自洽规则）。
- 忌：反派为配合主角送人头；失误零代价（逻辑豁免 ≠ 免死，失误必须付代价）。

**F5 说谎者三层瞒报**（出处：`对标/十日终焉/反派.md`）
- 触发：悬疑型反派（内鬼/说谎者）的瞒报设计。
- 机制：①规则宣誓训练立可信（人物当众立誓/有纪律背书）；②谎言藏在真话里
  （时态/量词/指代陷阱，每句单独都真）；③线索公平前置但注意力错位（线索早已
  出现，但被读者和主角当别的用途看过）。
- 变体：a 身份瞒报；b 动机瞒报；c 时序瞒报（把事件顺序说反）。
- 忌：洗白式翻底牌（黑幕翻完变温情）；揭晓的关键线索前文零出现。

**F6 兽性上限智商管理**（出处：`对标/我在精神病院学斩神/反派.md`）
- 触发：非人反派（怪物/异种/天灾）的威胁设计。
- 机制：行为规则提前立清（猎食偏好/行动规律），供主角反推求生——怪物的可怕
  来自规则不可违而非智谋；战略智能全归人类阵营（人类的布局才是真的可怕）；
  怪物「聪明」只限生理层（假死/移躯）。
- 变体：a 规则可反推型；b 进化型（规则中途升级且提前给征兆）。
- 忌：怪物突然会战略思考；规则中途改写无征兆。

**F7 单盲场景当分期利息**（出处：`对标/我不是戏神/反派.md` 信息差节）
- 触发：马甲/身份类信息差兑付。
- 机制：读者全知+主角单盲（主角马甲在场被议论的尴尬戏）是最高频爽点，20–30 章
  一次、每次配真实生理代价（冷汗/濒死风险）；掉马靠证据渗漏，长卷「只渗不破」。
- 变体：a 在场议论型；b 被迫配合演出型；c 少数人反超主角（有人识破而不揭穿）。
- 忌：高频单盲（读者腻）；单盲零代价变纯装逼。

**F8 谷期保温**（出处：`对标/我在精神病院学斩神/反派.md` 压迫源轮换节）
- 触发：两大压迫源之间的低危段。
- 机制：零致命压力谷用低危威胁保温（围剿戏/官僚刁难/社会性麻烦），压力线不归零；
  温暖场景越具体、反派越近——家宴/日常戏给下一波危机攒人质。
- 变体：a 低危围剿保温；b 日常温暖攒人质；c 暗线推进保温（幕后一层在动）。
- 忌：谷期完全无压力线（读者掉速）；温暖场景与后续危机无关（白暖）。

**F9 BOSS 战三件套**（出处：`对标/诡秘之主/反派.md`、`对标/我不是戏神/反派.md` BOSS 对决节）
- 触发：卷尾/大节点 BOSS 战细纲。
- 机制：①规则前置——胜负机制开打前亮明（BOSS 的规则级能力先展示过）；②不可逆
  代价——人命/能力榨干/身份暴露，债当场结清；③胜利孵化下一问题或更大棋盘
  （胜利的产出是入场券不是安全感）。胜负手在战斗之外：前置免疫/禁锢先于杀伤/
  献祭位（队友代价换胜机）。
- 变体：a 认知胜利（打赢的是「理解」不是武力）；b 惨胜（代价重于收益）；
  c 不战而胜（规则漏洞/谈判）。
- 忌：纯武力对轰；胜利零代价；胜利后世界照旧。

**F10 主角自救写进反派预案**（出处：`对标/宿命之环/反派.md` 信息差节）
- 触发：幕后型反派（不出手、只做局）的压迫写法。
- 机制：信息差单向透明——主角每步自救被反派预案逐条点破（求死被掐/求援被截），
  压迫感来自「我的挣扎在对方剧本里」；最终破局靠预案外的情感溢出或第三人变量，
  忌破局靠反派突发失误。
- 变体：a 自救全被点破+情感溢出破局；b 自救被点破+第三人变量破局；
  c 半透明（反派缺一块关键情报，主角赌它）。
- 忌：反派全知到无解（必须留预案外变量）；破局靠降智。
