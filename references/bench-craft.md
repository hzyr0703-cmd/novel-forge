# 对标库手法池（防模板版）

> 定位：v3.2 新增。来自五本头部对标书（《我不是戏神》《我在精神病院学斩神》
> 《诡秘之主》《宿命之环》《十日终焉》）语义层拆解——即 `book-teardown.md`
> 七步产物（概要/角色/剧情/设定/金手指/爽点抽样/文笔风格）——中**被验证过**
> 的结构与文笔手法，蒸馏成「选择项池」。
>
> 它不是流程、不是检查清单、不是句式库。`chinese-prose-craft.md` 管笔力本体、
> `human-texture.md` 管人味、`scene-architecture.md` 管场景骨架——与它们冲突时
> 一律以那三份为准。本文件只做一件事：写不下去、需要一件被头部书验证过的工具时，
> 多一个选项。

## 一、防模板纪律（先读这个，再看手法）

1. **手法是菜单，不是工序**。动笔前先回答「这一章的读者情绪任务是什么」，
   再看池子里有没有一件工具恰好服务它；没有就直写。禁止逐项核对「这章用了几个
   手法」——手法被指标化就会触发 P18（门禁越严正文越像 AI，见 `pitfalls.md`）。
2. **冷却制**：同一张结构卡（A 层）5 章内不复用，章级卡（B 层）3 章内不复用。
   `check-cross-diversity.py` 只查开头/结尾/爽点类型的同型，手法同型靠自检。
   同一**变体**连用两次，按复读处理。
3. **变体制**：每张卡带 2–3 个变体。命中触发条件 ≠ 照第一个变体执行——
   先看本章人物、场景、信息差与哪个变体贴合，选完允许再改造。
4. **拆结构不拆句子**：对标书句式只允许抽象成机制后重写，不允许保留原句骨架
   换词。这同时是版权纪律（`book-teardown.md` 文件头）与 AI 指纹纪律
   （整句移植对标句式，是另一种模板腔）。
5. **让位规则**：与项目追踪台账、用户当轮约束、本章细纲冲突时，一律让位。
   手法池是「多一个选项」，不是「多一个必须」。

## 二、消费流程（按需读，不全读）

书目录 `对标/<书名>/` 下：

| 要决定什么 | 读什么 |
| --- | --- |
| 卷级结构 / 势能台阶 | `概要.md` + `金手指.md` |
| 本章事件排布 / 爽点间隔 | `爽点抽样.md` |
| 落笔句感 | `文笔风格.md`（第 7 节是可迁移清单） |

日常章不必翻库。卡文、写卷首卷尾、写大爽点章、做卷纲时才翻。

## 三、手法池

### A 结构层（卷/弧级，低频；全书用量级 ≤ 卷数 × 2）

**A1 金手指生存契约**（出处：`对标/我不是戏神/金手指.md`、`对标/十日终焉/金手指.md`）
- 触发：金手指设定评审、升级节点设计。
- 机制：能力每次兑现都挂数值化代价或死线（期待值 <20% 即死 / 死亡即学费），
  爽点因付费而可信。
- 变体：a 死线挂稀有资源；b 死线挂人格/记忆损耗；c 死线挂身份暴露风险。
- 忌：死线常悬不落（狼来了）；每章都扣代价，爽文写成苦修文。

**A2 马甲经济学**（出处：`对标/我不是戏神/金手指.md`）
- 触发：设计主角信息层 / 身份层时。
- 机制：每层身份 = 一个爽点发生器 + 一根掉马引信；掉马时机按「读者早知道、
  场内人不知道」的信息差排。
- 变体：a 身份互为掩护；b 身份互相冲突（左手打右手）；c 身份被第三方冒用。
- 忌：马甲超过 3 层读者记不住；掉马零代价。

**A3 断点章**（出处：`对标/十日终焉/概要.md`）
- 触发：每 80–100 章的卷中部疲劳点。
- 机制：整章清账——集中翻底牌、回收悬置，把匀速悬念改成闸门式释放。
- 变体：a 自述型；b 对峙摊牌型；c 旁观者复盘型。
- 忌：连续两卷同一断点章型；断点章之后没有新债。

**A4 章型配对还债**（出处：`对标/我在精神病院学斩神/剧情/故事线.md`）
- 触发：还伏笔 / 情感债时。
- 机制：债的类型决定偿还章型——情感债用仪式/重逢章、谜题债用回溯章、
  规则债用回环章（意象首尾同现）。
- 变体：即机制中三型，可混合（一场重逢同时回环一个意象）。
- 忌：所有债都用解释性对白还。

**A5 卷尾「收 = 新问题」**（出处：`对标/十日终焉/概要.md`、`对标/诡秘之主/概要.md`）
- 触发：卷尾细纲。
- 机制：卷尾不解散压力，把已解规则升维成新问题（逃出十日 → 现实也在轮回）。
- 变体：a 老答案引出新问题；b 新视角重看旧事实；c 收掉一条线的同时另一条升一档。
- 忌：为钩而钩——新问题必须在既有设定里有根。

### B 章级（中频）

**B1 倒计时节拍器**（出处：`对标/我在精神病院学斩神/金手指.md`）
- 触发：回报需要跨章拖延时。
- 机制：可视化进度（进度条 / 搜索逼近 / 倒数），读者随时知道回报多远——
  拖延而不失耐心。
- 变体：a 敌方进度条；b 我方充能条；c 双条赛跑。
- 忌：一卷内连用；进度造假（说 85% 却三章不动）。

**B2 白嫖 + 身份倒置**（出处：`对标/我在精神病院学斩神/金手指.md`；与白嫖强者流同构）
- 触发：收服 / 借力桥段。
- 机制：收服条件数值化（可量化门槛），得手后身份倒置（强者变打工人），
  威严与反差双吃。
- 变体：a 倒置带隐情（假意臣服）；b 倒置带职责（按契约干活）；c 倒置带成长（效忠度可变）。
- 忌：反复倒置同一个人的威严——反差会通胀。

**B3 先立威后报价**（出处：`对标/宿命之环/金手指.md`）
- 触发：谈判 / 收编 / 交易场。
- 机制：冷酷展示 → 恐怖确认 → 反转收账（「恭喜你通过考验」式），威慑先行、
  条件后置。
- 变体：a 报价收人；b 报价收情报；c 报价收时间（拖延敌人）。
- 忌：每次谈判同款三段；对方无理由配合。

**B4 预埋—引爆暗手**（出处：`对标/宿命之环/金手指.md`）
- 触发：主角不能亲自出手的局。
- 机制：提前 2–3 章埋无关注意项（一句话 / 后门 / 心理暗示），当章引爆 + 两行内
  复盘自解释——爽感来自「原来早埋了」。
- 变体：a 借敌之手；b 借规则之手；c 借队友之口。
- 忌：预埋不进伏笔台账（会撞 `check-factconflicts.py`）；复盘超两行。

**B5 群像测温扬名**（出处：`对标/诡秘之主/概要.md`、`爽点抽样.md`）
- 触发：扬名 / 威慑需要呈现「量级」时。
- 机制：不写主角写旁观者，反应链测出量级（围观 → 业内 → 顶层三镜头）。
- 变体：a 三镜头递进；b 单镜头留白（只写最高层反应）；c 反向测温（敌人慌了）。
- 忌：与 `human-reaction.md` 群体分裂原则冲突的「全场一致」反应链。

### C 句级（高频；必须混用，单项不连章）

**C1 对话末句炸弹**（出处：`对标/十日终焉/爽点抽样.md`、`文笔风格.md`）
- 触发：高对话章的爽点引爆位。
- 机制：揭晓句放对话最后一句、短句收；前文对话全是铺垫。
- 变体：a 自认式；b 点破式；c 沉默式（动作代替揭晓句）。
- 忌：连续章节都用对话揭晓；揭晓句配感叹号 + 排比。

**C2 画面定格 + 半句掀前提**（出处：`对标/诡秘之主/文笔风格.md`）
- 触发：章末钩选择。
- 机制：先给完整安定画面，最后一句改变画面性质——比悬念省略号省字且不装。
- 变体：a 定格物证；b 定格反常动作；c 定格时间错位。
- 忌：每章同用；钩子与本章内容无关的硬切。

**C3 仪式感升级四步**（出处：`对标/诡秘之主/金手指.md`）
- 触发：借力 / 收服 / 升级的呈现章。
- 机制：异象 → 能力清单 → 身份自答 → 他人反应链，给力量获取「受洗级」重量，
  防白嫖贬值。
- 变体：a 完整四步（大节）；b 砍清单留异象 + 反应（中节）；c 倒叙（先反应后异象）。
- 忌：每次小借力都全套——重量感来自稀缺。

**C4 短句连击与留白**（出处：`对标/十日终焉/文笔风格.md`、`对标/我不是戏神/文笔风格.md`）
- 触发：紧张 / 恐怖 / 战斗段。
- 机制：紧张段把叙述句压到最短（主谓宾），威胁不写满；数字具象威胁
  （先给数字后炸真相）；战斗按场面选一招一段或连招流水。
- 变体：a 短句连击 + 单行长句呼吸；b 数字具象威胁；c 规则文本半遮。
- 忌：全章短句（单调）；留白过度（读者看不懂发生了什么）。

**C5 环境写心理**（出处：`对标/诡秘之主/文笔风格.md`、`对标/宿命之环/文笔风格.md`）
- 触发：情绪戏需要镜头退半步时。
- 机制：不写「他很难过」，写环境里与他状态共振的一两个物件，环境承担心理职能。
- 变体：a 物件异化（熟悉物陌生化）；b 环境节奏同构；c 环境反差（大喜写冷景）。
- 忌：环境描写连超 3 行（拖番茄节奏）；与 `narrative-distance.md` 过滤器动词
  冲突的「他看见……」句式。

## 四、密度与节拍标尺（对标书实测，校准用）

| 书 | 末 10 章爽点密度 | 三拍占比（连续 5 章） | 句长 / 对话占比 |
| --- | --- | --- | --- |
| 诡秘之主 | 0.2/章 | 铺 40–55 : 冲 15–45 : 收 ≥25 | 29.7 / 25.7% |
| 宿命之环 | 0.7/章 | 铺 50 : 执 30 : 报 20 | 31.3 / 28.0% |
| 我不是戏神 | 0.3–1.0/章 | — | 19.7 / 25.4% |
| 斩神 | 1.5/章 | 章章小爽、三章一大爽、大回报独立成章 | 22.2 / 24.8% |
| 十日终焉 | 1.1/章 | 阻碍 35–60、代价可整章一事、回报压章末 | 18.2 / 37.1% |

- 番茄快节奏校准线：对标斩神 / 十日（1.0–1.5 个/章）。
- 三拍占比在 铺 40–60 : 执 15–45 : 收 20–35 内按当章类型浮动；
  **同配比连用三章 = 节拍模板化**，主动换档。
