# 文风基线 · 冷硬都市（v2.0 · 冷燃版）

> **赛道**：都市脑洞 / 都市异能 / 都市悬疑 / 都市高武
> **一句话**：句子短，动词狠，画面冷；冷到极处，才点一把火。
> **定位**：novel-forge 的**默认文风**：都市向、未指定文风时自动套用。
> **v2.0 变更（2026-11-01）**：从“短句+少形容词”升级为可执行的六项笔力指标；新增“冷燃”要求（冷硬不是干巴），新增对话潜台词与章末四种收束。

---

## 一、句法：短句为主，长短交替

- 平均句长 15–22 字；短句（≤10 字）占比 35–45%。
- **连续 5 句短句后，必须给一个 30 字以上的长句**，否则读者喘不上气。
- **40 字以上长句占全部句子 ≥10%**（2100 字/章约 8–12 句；与 `check-distribution.py` 的 10% 预警线一致），用于铺陈、回忆、情绪漫上来的一瞬。
- 动词密：一句里常有两个以上动作动词，形容词最多一个。
  - 例：「他拧开门，侧身进去，反手带上。」

## 二、动词与画面：先给画面，再给判断

- 删掉「非常」「极其」「不可思议地」。用后果代替程度。
  - 不写「他非常愤怒」，写「他把杯子摔在墙上，碎片弹回来，划了他自己的手」。
- **每 300 字至少两种感官**（视觉之外必须有听觉/嗅觉/触觉/体感）。
  - 只有视觉：屋里很旧。
  - 加嗅觉：屋里一股旧棉絮混煤灰的味。
  - 加触觉：手按在桌沿上，一层黏。
- 白描优先：写动作与物件，不写评述。
  - 不写「他很穷」，写「他的鞋底缠着三圈黑胶布，鞋是白的」。

## 三、段落：短段为主，允许一次长呼吸

- 段落多在 **30–60 字**（人类基线 p50≈31、p75≈46），一段 1–3 句；15–25 字的短段只用于砸节奏。
- 一章允许 2 段 80–90 字的长段（场景铺陈/情绪回流）；**硬上限 90 字，与门禁一致**，超过 2 段节奏就塌。
- 单句成段只用于强调动作或转折：「他没动。」一章 ≤3 次。

## 四、对话：话里有话，话外有动作

- 对话短促，一句 10–20 字。
- **信息藏在动作里**，不靠台词直说。
  - 不写「我现在很生气」，写「他把烟按灭在烟灰缸里，碾了两下」。
- **潜台词**：人物说的和想的差一层。
  - 表层：「你吃了吗。」 里层：「你昨晚没回来。」
  - 写法：问完不等人答，先给他盛饭。
- 口癖要有，但废话要克制：「嗯。」「行。」「知道了。」
- **每个人物有自己的句长与口癖**（见 05-人物群像集语言指纹表），禁全员一个腔。

## 五、比喻与形容词

- 形容词总量 ≤3%。
- 比喻要具体、要狠，不用「仿佛」「如同」「宛如」起头的套式。
  - 不写「痛得如同刀割」，写「痛得像有人拿钳子夹住了骨头」。
- 一章比喻 ≤4 个。超过就是炫技，读者会跳。
- **冷燃点**：全章冷硬，允许在情绪最高处点一句“热”的（一句，不超过 20 字）。
  - 例：「他站在门口，觉得这屋子有点暖。」只此一句，多了就腻。

## 六、章末：四种收束，禁问句

| 类型 | 用法 | 例 |
|---|---|---|
| **判决句** | 主角下结论 | 「这笔账，记上了。」 |
| **定格** | 一个画面停住 | 「灯灭了。手背上那道痕还亮着。」 |
| **反讽** | 用他人的话反收 | 「他们都以为他输了。」 |
| **倒计时** | 时间压下来 | 「三天。够他把账翻一遍。」 |

**禁**：问句钩（「他该怎么办？」）、总结式升华、作者跳出来感慨。

## 七、独有约束对照表

| 项 | 冷硬都市（v2.0） |
|---|---|
| 平均句长 | 短（15–22），但长句占比≥10% |
| 短句占比 | 35–45% |
| 长句（≥40 字） | 占全部句子 ≥10% |
| 感官 | 每 300 字 ≥2 种 |
| 形容词 | ≤3% |
| 比喻 | ≤4 个/章，禁套式 |
| 允许抒情 | 极少量，仅“冷燃点”一句 |
| 叙述者跳出来 | 禁止 |
| 章末 | 判决/定格/反讽/倒计时，禁问句 |

## 八、差→好 对照（写作时随手翻）

| 差 | 好 |
|---|---|
| 他感到很紧张。 | 他把打火机点了三次，才点着。 |
| 房间里很安静。 | 安静得能听见灯泡里的电流声。 |
| 他很厉害。 | 他抬手，三个人同时退了半步。 |
| 她生气了。 | 她把筷子放下，放得很正。 |
| 气氛很压抑。 | 没人说话。有人把椅子往后挪了挪，又挪回来。 |
| 他决定反击。 | 他把袖子往上卷了两折。 |

## 九、与硬规格的关系

本文件是**风格指引**，不是机检项。它影响“读起来像不像人写的”，不影响 `forge.py gate` 的 blocking 判定；blocking 只看字数/段长/AI味/章末钩子四项。
跨章多样性（开头/结尾方式）见 `scripts/check-cross-diversity.py`。
