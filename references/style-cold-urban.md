# 文风基线 · 冷硬都市（默认男频）

> **赛道**：都市脑洞 / 都市异能 / 都市悬疑
> **一句话**：短句为主，动词密，少形容词，对话短促，叙述克制。
> **定位**：这是 novel-forge 的**默认文风**——用户未指定文风且赛道为都市向时自动套用。

## 一、句法

- **短句为主**：平均句长 15–22 字，短句（≤10 字）占比 40%+。
- **动词密**：一句话里常有两个以上动作动词，形容词最多一个。
  例：「他拧开门，侧身进去，反手带上。」
- **少修饰**：删掉「非常」「极其」「不可思议地」。用后果代替程度。
  例：不写「他非常愤怒」，写「他把杯子摔在墙上」。

## 二、段落

- 段落偏短：多在 20–40 字，一段 1–3 句。
- **允许偶尔长段**（80–120 字）做场景铺陈，但一章不超过 2 段——否则节奏塌。
- 单句成段用于强调动作或转折：「他没动。」

## 三、对话

- 对话短促，一句多在 10–20 字。
- 信息藏在动作里，不靠台词直说。
  例：不写「我现在很生气」，写「他把烟按灭在烟灰缸里，碾了两下」。
- 允许口癖，但不许废话太多——都市冷硬向的废话是**克制的**废话（「嗯。」「行。」）。

## 四、形容词与比喻

- 形容词总量控制在 3% 以内。
- 比喻要具体、要狠，不要「仿佛」「如同」起头的套式比喻。
  例：不写「痛得如同刀割」，写「痛得像有人拿钳子夹住了骨头」。

## 五、独有约束（相对其他基线）

| 项        | 冷硬都市        |
| -------- | ----------- |
| 平均句长     | 短（15–22）    |
| 允许废话     | 极少          |
| 允许抒情     | 几乎不         |
| 叙述者跳出来   | 禁止          |
| 章末钩子     | 偏动作定格/悬念    |

## 六、与硬规格的关系

本文件是**风格指引**，不是机检项。它影响的是「读起来像不像人写的」，
不影响 `spec_check.py` 的 blocking 判定——blocking 只看字数/段长/AI味/章末钩子四项。

跨章多样性（开头/结尾方式）见 `scripts/check-cross-diversity.py`。
