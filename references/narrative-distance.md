# 叙述距离（narrative-distance）

> 补一层 `human-reaction` / `human-texture` 都覆盖不到的：**叙述者站在离人物多远的地方**。
>
> - `human-reaction` 管「一群人像不像人」（群体层）
> - `human-texture` 管「一个人有没有失控感」（个体层）
> - 本文件管「**镜头**」——同一个人的同一件事，站远了是新闻，站近了是伤口
>
> 三个文件互不替代。人群全对、人物也活，但叙述者一直站在三米外念解说词，稿子照样是死的。

## 原理：五档距离

距离不是「第一人称 / 第三人称」，是**叙述者离人物内心有几级台阶**。五档，从远到近：

| 档 | 定义 | 长什么样（同一件事：林灼看见手背上的痕） |
|---|---|---|
| **1 远景** | 时代、地点、一群人，没有具体人 | 「验碑那天，广场上排了三百多人。」 |
| **2 概览** | 有名有姓，但只从外面看 | 「林灼站在队尾，袖子拉得很低。」 |
| **3 直陈** | 直接说出他的情绪 | 「他心里一沉。」／「他感到一阵不安。」 |
| **4 近** | **他自己的话渗进叙述**，没引号、没有「他想」 | 「又是这样。别人的字亮得晃眼，他这儿什么都没有。」 |
| **5 深** | 原始感官、联想、碎片、意识流动 | 「白。白的。手背那道痕开始烫，像有人拿指甲在皮里划字。」 |

**判档看四个标记同时收敛，看一个必错：**

1. **称名**：无名（「一个男的」）→ 全名 → 只叫姓 → 只用人称 → 最深时连称呼都没有
2. **内心**：只写动作 → 写偏好 → 直说情绪 → 情绪用他自己的话 → 无中介的感官
3. **自由间接引语**：第 4 档的标志——人物的话混进叙述，不加引号，也不加「他想」
4. **句法**：碎片句、无主语句、第二人称，都是深档信号

## 唯一能数的那条：过滤器动词

> 看见 / 看到 / 听见 / 听到 / 感到 / 觉得 / 注意到 / 发现 / 察觉 / 意识到 / 闻到 / 想起 / 明白 / 知道

这些词的作用是**把读者挡在一臂之外**：不是让读者看见，是告诉读者「他看见了」。

| 挡住的写法 | 拆掉的写法 |
|---|---|
| 他听见身后有人笑。 | 身后有人笑。 |
| 他看见赵铁的右手在抖。 | 赵铁的右手在抖。 |
| 他感到那道痕在发烫。 | 那道痕在发烫。 |
| 他发现自己的名字不在册上。 | 册子上没有他的名字。 |

**三步改法**：删掉感知动词 → 把被感知的东西直接摆出来 → 检查主语还在不在（不在也常常更好）。

一条底线：**过滤器动词不是禁词**。它是距离的旋钮，不是错误。「他忽然明白了一件事」在需要减速的地方是好句子。要防的是**堆叠**——一段里三个，读者就被推到了三米外。

## 网文落位（本书口径）

| 场景 | 该在哪档 | 理由 |
|---|---|---|
| 开篇定场、卷首、大战全景 | 1–2 | 先给世界，再给人 |
| 日常推进、对话场 | 2–3 | 网文默认档，节奏需要 |
| 情绪转折、被冤枉、被围观 | **4** | 这一档最值钱：读者听到的是他自己的声音 |
| 受伤、濒死、狂喜、顿悟、醉酒 | **5** | 猛药，一章最多一次，多则失重 |

**第 3 档是 AI 味的重灾区。** 「他心里一沉」「一股无力感涌上来」「说不出的难受」——这些不是错，是**偷懒**：叙述者替人物总结了情绪，读者什么也没感到。

改法只有一条：**把第 3 档改写成第 4 档**——不写「他感到愤怒」，写他此刻会脱口而出的那句话（不加引号）。

## 三条禁令

**N1 不许用人称判距离。** 第一人称可以站在最远档（「我叫林灼，那年十七，住在城西。」），近距离第三人称可以站在最深档。人称是语法，距离是镜头。

**N2 不许把「近」当「好」。** 一直贴着脸写，读者会累，也会失去判断权。该远的地方远（交代、过场、群像），该近的地方近（转折、代价、失去）。**一章里至少一次升降，且升降要有理由。**

**N3 同一场景内不许跳档，除非有过桥。** 从 2 档直接跳到 5 档，读者会以为串行了。跳档必须给一个物理动作或一个物件当桥：他低头看手 → 痕 → 烫 → 碎片。

## 自检五问

1. 这一章的**主场景**在第几档？说得出来吗？（说不出＝没控制）
2. 全章有没有**至少一次**升到第 4 档？（没有＝全程解说词）
3. 第 5 档用了几次？超过一次就删。
4. 有没有**连续两段**在第 3 档直陈情绪？（有＝偷懒区）
5. 圈出所有过滤器动词，逐个问：删掉它，句子是不是更近？（是就删）
