# X 级已否决信号清单

> **这张表的作用不是「记下我们没查的」，是「记下我们查过、而且查反了的」。**
> 每条都写着「为什么推翻」，并且有一条可执行的守卫（`scripts/test-rejected-signals.py`）。
> 目的只有一个：**防止未来的自己又把它们加回规则表**。

## 一、为什么需要这一档

lint 只有两级：blocking（必须清零）/ advisory（提示）。这两级都假设「命中 = 有毛病」。
但有一类特征，命中的是**人类写作的常态**：

- 第一轮不配对对照里看着像 AI 味（因为话题混杂）；
- 同题同事实配对复测后，人类用得**比 AI 还多**，或者根本没有差异。

这类特征如果留在规则里，危害比漏检大：

1. **模型会把真写法改掉**。破折号打断对话是中文的唯一写法，改掉读者就分不清谁打断谁。
2. **门禁在奖励更假的文字**（同 v2.8 那条「禁词不禁族」）。它会教出一套替换表：
   「仿佛→好像」——换完还是比喻，语义、节奏、画面一模一样。
3. **规则库只增不减**。每次有人觉得「这个像 AI」就加一条，三年后没人说得清哪条还有效。

所以加第三档：**X 级 —— 照常计数，明确标不改。**
命中 X 级时 lint 不出 finding、不进退出码，但 `--diff` 与文档里留着记录，**因为「不改」本身是结论**。

## 二、进 X 级的三条门槛

必须至少满足一条，且写成可复核的依据：

1. **配对复测反转**：同题同事实对照后，人类使用频率 ≥ AI。
2. **配对复测归零**：差异 `|Cliff's δ| < 0.2`，统计上无差异。
3. **口径不可比**：两条统计的分母/切分方式不同，数字不能直接比（此时保留原始观察，不许立规则）。

> 来源：`larashero3-dotcom/lieflat-less-ai-tone`（CC BY-NC 4.0）两轮实验——
> 629 篇不配对对照（AI 300 篇 / 117.9 万字 × 5 模型，人类 329 篇 / 164.8 万字）+
> 270 对同题同事实配对复测 + 43 万次语义判断，90 项指标，配对 Wilcoxon + Cliff's δ。
> 它的语料是**非虚构文章**，我的是网文——所以只搬「方向」，一个频率阈值都没搬。

## 四、怎么用这张表

**写正文时**：不要为了「像人」去加 X 级里的东西，也不要因为 lint 报了 advisory 就删。
X 级的意义是「这条不用管」——不是「这条很高级」。

**改规则时**（包括我）：

1. 想加一条规则前，先在这张表里搜关键词。命中就说明查过了，去看「为什么推翻」。
2. 真要推翻 X 级结论，必须给出**配对复测**级别的证据，不能凭语感。
3. 加进去就跑 `python scripts/test-rejected-signals.py`——它会拦下 X-2 / X-7 的回归。

**跑机器检查**：

```bash
python scripts/test-rejected-signals.py       # 守卫 + 行为对照，退出码 1 表示有人把已否决特征加回去了
```

## 五、X 级 ≠ 不重要

被否决的是「**它是 AI 指纹**」这个判断，不是「它不好」：

| 现象 | 它可能真的是问题 | 但归谁管 |
|---|---|---|
| 「仿佛」成段堆叠 | 是，读起来腻 | `metaphor-density-tic`（同段 ≥3），归 `literary` 类 |
| 「这意味着」连着用三次 | 是，像报告 | 人工 21 问的语感项，不归 lint |
| 全章没有长句 | 可能是，节奏平 | `check-distribution.py` 的诊断问句，不设 KPI |

所以 X 级不是「免检」，是「**换个理由管**」：从「因为像 AI 所以改」换成「因为读起来
如何所以改」。前者会把真人写法改坏，后者才是编辑该做的事。
