> 移植自 tomato-viral-novel（MIT），门禁部分对接 `forge.py gate`。
>
> **核心事实：番茄的推荐算法在第一章就决定要不要给量。前 300 字是最贵的三百字。**
>
> **2026-10 核验增补：开篇判定窗口还在前移。** 网上流传的「开篇法则已从
> 黄金三章坍缩成生死七行」这句话查无官方出处，**不要当术语引用**；但窗口
> 前移本身有可查证依据：①番茄编辑评估新书的硬门槛之一是**第一章前 300 字
> 让金手指前兆露头**（来源：wangwen666 网文金手指南，2026-10-07 核验）；
> ②编辑初审通行「三秒抓眼」：第一段必须抛冲突，杜绝上千字背景介绍
> （来源：番茄过签攻略，2026-07）；③签约数据自查线：**前三章完读率 ≥30% +
> 收藏 ≥150 才建议申签**，否则先改开篇。本文件第 1 章 8 段骨架与 S1–S5
> 五句链就是按这个窗口设计的——「生死七行」描述的现象是真实的，数字别照抄。

## 一、硬指标（机器可校验）

| 指标 | 硬线 |
|---|---|
| 冲突出现位置 | ≤ 前 300 字（编辑「三秒抓眼」线：第一段即冲突） |
| 主角登场位置 | ≤ 前 500 字（必须出现主角**名字**） |
| 金手指前兆露头 | **≤ 前 300 字（2026-10 核验：编辑评估新书的硬门槛之一）** |
| 金手指出现位置 | ≤ 第 3 章（第 1 章前兆、第 2 章显形、第 3 章使用） |
| 首次小爽点 | ≤ 第 3 章 |
| 第 1 章末 | 必须留核心悬念 + 标钩子型号 |
| 第 3 章末 | 必须挂长线钩子 + 完成第 1 势能跃升 |
| 微钩子密度 | 每 500 字 ≥ 1 |
| 章末钩子 | 连续两章不得同型，需显式标注 `<!-- 钩子型号：HN -->` |
| 段落长度 | ≤ 60 字（手机屏3–4 行硬约束） |
| 对话占比 | ≥ 25%（开篇更高） |
| 爽点节点 | 每 500–800 字 ≥ 1（3000 字章约 4–6 个） |

> **签约数据自查线（2026-10 核验）**：前三章完读率 ≥30% 且收藏 ≥150 再申签；
> 低于此线先重写开篇，不要浪费 2/5/8 万字的三次申签机会。
> 编辑初审最常见拒签理由：前三章无冲突、无金手指、节奏缓慢。

## 二、开篇 300 字五句链

前 300 字 = 5 句功能链，一句都不能少：

| 句序 | 功能 | 骨架 | 示例 |
|---|---|---|---|
| S1 | 制造异常 | 【常规动作】到一半，【异常事实】 | 加班到凌晨三点，林川的工位上多了offer——一个他从没投过的公司 |
| S2 | 给出代价 | 这意味着，【主角即将失去的东西】 | 他攒了三年的首付，今晚就得打水漂 |
| S3 | 主角反应 | 盯着【异常物】，没有【常规反应】，而是【非常规动作】 | 他没报警，把它折起来塞进了兜里 |
| S4 | 抛利害 | 因为他知道一件别人不知道的事：【信息差】 | 这家公司上一个签字的人，坟头草已经两米高了 |
| S5 | 留缺口 | 而【威胁/机会】已经在路上了——【具体时间地点】 | 发offer的人已在楼下。电梯显示：3、2、1 |

**禁忌**：S1 禁天气/环境描写开场（2026 样本此类完读率垫底）；S1–S5 出现两个以上人名。

## 三、黄金三章逐段骨架

### 第 1 章（2000 字 · 8 段）

| 段 | 字数 | 功能 |
|---|---|---|
| P1 | 300 | 黄金开局五句链 |
| P2 | 300 | 冲突具象化（压力源露头，只给言行不给背景） |
| P3 | 250 | 主角立场（一句台词 + 一个动作表明不吃这一套） |
| P4 | 300 | 初次交锋（小规模试探，小赢或惨平，**禁大胜**） |
| P5 | 250 | 金手指暗示（异常细节闪现一次，主角自己都没察觉） |
| P6 | 300 | 危机升级（具体困境：欠款/期限/威胁三选一） |
| P7 | 200 | 情绪落点（一句狠话或一个决定） |
| P8 | 100 | 章末钩子（标型号，与下章不同型） |

### 第 2 章（2200 字）

- 前 400 字：兑现第 1 章钩子的第一层（**只兑现 30%，留 70%**）
- 中 1000 字：金手指第一次显性生效，解决一个**小**问题
- 后 600 字：更大压力入场（第 1 章反派的上级/关联方）
- 章末钩子：换型，优先 H3/H4/H6

### 第 3 章（2400 字 · 首次打脸）

- 前 500 字：反派阵营集结，**当众**施压（公开场合 = 打脸放大器）
- 中 1200 字：三段式打脸，金手指只展示一个功能
- 后 500 字：旁观者反应轮（围观群众/边缘人物/反派靠山各 1–2 句）
- 章末钩子：H1/H5/H12，完成第 1 势能跃升

## 四、章末钩子 12 型

| 型号 | 名称 | 句式骨架 |
|---|---|---|
| **H1** | 身份揭示 | 「站在门外的，是三年前已经死掉的那个人。」 |
| **H2** | 认知颠覆 | 「他一直以为自己是受害者。」 |
| **H3** | 危机倒计时 | 「三天后，他会死。」 |
| **H4** | 未知来客 | 「门外的脚步声，不止一个人。」 |
| **H5** | 反转打脸 | 「他打开文件，签的不是自己的名字。」 |
| **H6** | 秘密线索 | 「箱子最底层，压着一张十年前的照片。」 |
| **H7** | 抉择两难 | 「要么交出她，要么看着所有人死。」 |
| **H8** | 复仇宣言 | 「他记住了这张脸。」 |
| **H9** | 规则异变 | 「从今天开始，说谎的人会立刻消失。」 |
| **H10** | 情感撕裂 | 「她没接电话。第三次了。」 |
| **H11** | 悬念提问 | 「这场火，到底是谁点的？」 |
| **H12** | 力量觉醒 | 「他低头看着自己的手。指尖在发光。」 |

**选型纪律**：
1. 每章必须选型并标注，不允许无型号
2. 连续两章不得同型
3. 同卷内同型号不得超过 4 次
4. 型号要与情绪匹配：压抑章 → H3/H7/H10；爆发章 → H1/H5/H12；悬疑章 → H2/H4/H6/H11

**章末禁用句式**：「欲知后事如何」「这一夜无人入眠」「命运的齿轮开始转动」「未完待续」「然后他睡着了」

> 注：`trailer-ending` / `trailer-summary` 两类 blocking lint规则专门拦这些。

## 五、微钩子 8 型（每 500 字 ≥1）

| # | 型号 | 示例骨架 |
|---|---|---|
| M1 | 悬念型 | 「他为什么不肯说出那个名字？」 |
| M2 | 转折型 | 「门开了。进来的不是医生。」 |
| M3 | 揭示型 | 「照片背面写着一行字：别信他。」 |
| M4 | 倒计时型 | 「还剩六十秒。」 |
| M5 | 系统提示型 | 「【检测到生命威胁，反击模块已激活】」 |
| M6 | 疑问型 | 「难道他们也以为我死了？」 |
| M7 | 场景异变型 | 「整栋楼的灯，全灭了。」 |
| M8 | 情绪反差型 | 「他笑了。笑得在场所有人脊背发凉。」 |

**密度纪律**：≥1/500 字，但不要每句都是钩子——密度过高读者会疲劳。

## 六、章中钩子（第 40%–60% 位置）

当反派刚吐出半个名字就被一脚踹门打断，读者的心智任务被迫悬置——这种「进行中的断裂感」比看完一整章再抛悬念强数倍。

每章建议 1 个章中钩子（对话中断 / 动作中断 / 异常画面突入）。

## 七、爽点桥段三段式

每类桥段 = 铺垫 → 引爆 → 余韵，字数配比 **1 : 1.5 : 0.5**。

| # | 桥段 | 铺垫（憋） | 引爆（爽） | 余韵（传） |
|---|---|---|---|---|
| 1 | 当众打脸 | 反派当众羞辱，旁人附和，主角沉默 | 亮底牌 + 证据翻盘 | 「整个包厢安静得能听见冰块化开」 |
| 2 | 扮猪吃虎 | 所有人认定他是废物 | 关键场合身份露一角 | 有人开始重查主角底细 |
| 3 | 绝境翻盘 | 资源时间退路全断 | 用 ≥2 章前埋的伏笔翻盘 | 反派内讧，怀疑有内鬼 |
| 5 | 扮猪吃虎·竞标版 | 被排挤出名单 | 规则漏洞合法重返并碾压 | 对手股价波动 |
| 6 | 强者认证 | 权威场合被质疑资格 | 领域最高权威主动让位 | 「他师父是谁」成新悬念 |
| 9 | 悬疑·真相砸脸 | 线索全指向错误结论 | 一件物证推翻全部推理 | 真凶背后还有一只手 |

**使用纪律**：同一桥段类型 10 章内不超过 2 次；**打脸对象必须升级**（马仔→主管→老板→靠山）。

## 八、三重回报模型（每章自查）

一章读完，读者至少要拿到三样中的**两样**，否则弃书概率大幅上升：

| 回报类型 | 内容 |
|---|---|
| 信息回报 | 知道了新的东西（谜团推进/真相靠近） |
| 情绪回报 | 爽了/甜了/燃了/揪心了 |
| 进展回报 | 变强了/拿到资源了/关系推进了 |

**答不出具体一项 → 该章必须重写。**

## 九、手术四刀（改稿顺序，不可颠倒）

| 刀 | 动作 | 解决 |
|---|---|---|
| 第一刀 | 前置冲突：把最激烈片段提到前 300 字 | 留不住 |
| 第二刀 | 前移爽点：第一个小爽点提到第 1–3 章 | 没回报 |
| 第三刀 | 加密钩子：每 500 字补微钩子 + 重写章末钩子 | 追不下去 |
| 第四刀 | 去 AI 味：跑 `check-ai-patterns.js` | 机械感 |

**纪律**：四刀做完必须重跑 `forge.py gate --stage all`，退出码 0 才交付。
