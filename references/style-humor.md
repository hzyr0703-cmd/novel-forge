# 文风基线 · 幽默吐槽

> **赛道**：脑洞 / 轻喜剧 / 沙雕向 / 系统流（带吐槽）
> **一句话**：自嘲、插科打诨、叙述者跳出来说话，节奏跳脱。
> **定位**：赛道为脑洞/轻喜剧，或用户指定「搞笑」「沙雕」时套用。

## 一、句法

- **节奏跳脱**：正经句子后突然来一句不讲理的吐槽。
  例：「他屏住呼吸，凝神戒备，摆出了祖传的起手式。然后被一拳打飞了。」
- 允许极短句做梗的落点：「离谱。」
- 允许自问自答：「但是为什么是他呢?……因为他倒霉啊。」

## 二、段落

- 段落长短随意，跟着笑点走。
- 一个梗铺完就切段，不要拖。

## 三、对话

- 对话可以很密，也可以很碎。
- 允许弹幕式吐槽混进叙述层：
  例：「在场的所有人都愣住了（除了那个装作不愣的）。」
- 常用梗：反差、夸张、自我拆台、突然正经。

## 四、形容词与比喻

- 比喻要**歪**：「快得像上班迟到的人」「安静得像周一早晨的办公室」。
- 少正经理喻，多生活化、荒诞化的联想。

## 五、独有约束（相对其他基线）

| 项        | 幽默吐槽        |
| -------- | ----------- |
| 平均句长     | 跳跃（不定）      |
| 允许废话     | 大量，且是包袱     |
| 允许抒情     | 少，且常用来反衬笑点  |
| 叙述者跳出来   | 核心手法        |
| 章末钩子     | 偏台词/反转      |

## 六、与硬规格的关系

本文件是**风格指引**，不是机检项。blocking 仍只看字数/段长/AI味/章末钩子四项。
注意：吐槽向的「废话」和「插话」都是有意为之，不要被 AI 味检测误伤——但
硬禁词（忽然/不禁/非常等）仍然禁用，吐槽不等于用烂词。段长上限（90 字）也照守。
