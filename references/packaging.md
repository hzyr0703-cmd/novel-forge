# 吸量包装：书名 15 式 / 简介 5 结构 / 标签 / 书测

> 移植自 tomato-viral-novel（MIT）。**包装决定点击率，而点击率是番茄唯一不可事后补救的指标之一**（书测有次数限制）。

## 一、书名造词公式机

### 要素池（从本书设定取）

- **身份池**：战神/赘婿/神医/锦鲤/团宠/大佬/继承人/退伍兵/首富之女/重生者
- **状态池**：下山/回城/归来/重生/觉醒/闪婚/离婚/签到/开局/满级
- **反差池**：被赶出家门/被退婚/被当成废物/隐藏身份/被迫营业/只想躺平
- **结果池**：横扫/制霸/无敌/爆富/爆红/团宠全场/惊动全城/掀桌

### 六公式

| # | 公式 | 示例 |
|---|---|---|
| 1 | 状态+身份 | 【离婚】后，她成了【满级大佬】 |
| 2 | 身份+反差 | 【神医】下山，被当成【废物女婿】 |
| 3 | 开局+结果 | 开局【被退婚】，我【横扫】全场 |
| 4 | 身份+身份 | 当【战神】回归，【首富之女】追悔莫及 |
| 5 | 疑问钩 | 谁说【赘婿】不能【制霸】商界？ |
| 6 | 数字冲击 | 签到三年，我【无敌】了 |

### 红线

- 书名 ≤ 12 字优先
- 禁用平台限流词
- 禁止出现真实品牌与人名

## 二、简介 5 结构逐字模板

| 结构 | 模板 |
|---|---|
| 悬念式 | 【一句反常事实】。没有人知道【秘密】。直到【引爆事件】，【主角】不得不【行动】——而这一切，才刚刚开始。 |
| 爽点前置式 | 【被欺压场景一句话】。所有人都以为【主角】完了。直到他亮出【金手指】。【打脸结果一句话】。 |
| 身份反差式 | 【白天身份】；【黑夜身份】。两条平行线，在【事件】那天撞在了一起。 |
| 甜宠式 | 【相遇场景】。所有人都说他们不合适：【理由】。可他偏要把【世界/心】捧到她面前。 |
| 系统流式 | 【落魄一句话】。绑定【系统名】，开局奖励【奖励】。【任务一句话】。这一次，他要【目标】。 |

**硬指标**：≤ 120 字；最后一句必须是钩子；禁止剧透金手指全部规则。

## 三、标签布局

- **3–5 个高流量精准标签**，不是越多越好
- 前2 个必须是大盘高频词（决定初始流量池）
- 后 2–3 个用来做精准筛选（决定读者是否对味）
- 泛标签堆砌拿不到精准流量，D7 直接 ≤ 2 分

## 四、封面钩子

封面上的字不超过 8 个，只表达一个冲突或悬念，**不要把书名重复一遍**。

## 五、书测 A/B 决策矩阵

番茄提供新书书测机会，通常有两轮（20–50 万 / 100 万字阶段）。

| 情形 | 动作 |
|---|---|
| 书测已过，数据达标 | **不要动**已发布章节，改动 = 数据归零 |
| 书测已过，数据差 | 优先换书名（改动成本最低、不影响正文数据），其次换简介 |
| 未书测，数据未起量 | 先扫榜确认赛道没凉，再考虑重做开篇 |

**顺序纪律**：书名 → 简介 → 标签 → 开篇 → 换书。越靠后代价越大。

## 六、包装自检

- [ ] 书名 ≤ 12 字，命中至少一个公式
- [ ] 书名含情绪词或冲突词，不是纯文青
- [ ] 简介 ≤ 120 字，首 3 行给冲突
- [ ] 简介最后一句是钩子
- [ ] 标签 3–5 个，前 2 个是大盘高频
- [ ] 封面钩子 ≤ 8 字，不重复书名
- [ ] 全部通过 D5/D6/D7 三项打分
