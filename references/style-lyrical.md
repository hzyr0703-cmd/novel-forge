# 文风基线 · 抒情古风

> **赛道**：女频 / 古言 / 仙侠 / 言情
> **一句话**：长句为主，意象密，节奏慢，允许排比，对话文白相间。
> **定位**：赛道为古言/仙侠/言情，或用户指定「唯美」「古典」时套用。
> **说明**：本技能偏男频，此为跨频道备用基线，供女性向项目显式指定。

## 一、句法

- **长句为主**：平均句长 28–40 字，长句占比 40%+。
- **允许排比**：「是春日的柳，是夏夜的萤，是秋风里落了一地的银杏。」
- 节奏慢，一句可以铺很久，不急。
- 允许倒装、省略主语：「月色如洗，凉了一院。」

## 二、段落

- 段落偏长，一个画面一段。
- 意象密度高：一段里可以叠 3–4 个意象。
- 不追求快节奏，追求「韵」。

## 三、对话

- **文白相间**：人物身份决定语言——贵人偏文言，下人偏白话。
- 对话常带停顿、动作、神态描写：
  例：「她低眉，指尖在茶盏沿上转了半圈，『公子……当真不知?』」
- 允许含蓄、言在此意在彼。

## 四、形容词与比喻

- 形容词可以多，但要**雅**：「素」「绯」「澄澈」「清冷」。
- 比喻要意境化：「她的笑像三月未化的雪」。

## 五、独有约束（相对其他基线）

| 项        | 抒情古风        |
| -------- | ----------- |
| 平均句长     | 长（28–40）    |
| 允许废话     | 少，但允许留白式婉转  |
| 允许抒情     | 大量          |
| 意象密度     | 高           |
| 章末钩子     | 偏画面/心理      |

## 六、与硬规格的关系

本文件是**风格指引**，不是机检项。blocking 仍只看字数/段长/AI味/章末钩子四项。
注意：古风向长句多，易接近段长上限（90 字）——超过会触发 blocking，需按画面断段。
