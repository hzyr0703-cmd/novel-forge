## 一、平台基本盘

| 指标 | 2026 数值 | 创作含义 |
|---|---|---|
| 日活 | 破 3 亿 | 长尾品类也有活路 |
| 45 岁以上用户 | 1.21 亿，占 **45.7%** | 中年是基本盘：要爽、要直白 |
| 单月新书 | 超 6 万本（同比 +71%） | 会写不够，必须能爆 |
| 月收入 >2500 元占比 | **1.56%** | 收入是极小概率事件 |

**推论**：番茄是算法赛马。`点击 → 完读 → 加书架 → 追更 → 停留`，算法不读文字只读行为。

**给选题的直接推论**：
1. 新书进场优先 M3 都市脑洞 / M7 悬疑脑洞（增量坑位），M1 只在有碾压级
   差异化切口时碰（D2 ≥ 8 才允许 D1 过热进场）。
2. 智斗流的门槛是**规则自洽 + 无降智**——写前先过
   `references/anti-pattern-checklist.md` 的话疗/降智条款。
3. 金手指设计对照编辑硬门槛：前 300 字前兆露头 + 一句话能说清记忆点
   （详见 opening-surgery.md 硬指标表与 hit-formula.md 编辑评估三硬门槛）。

```
第1步 · 定频道

  女频 → F1 豪门总裁 / F4 现言脑洞（兽世）/ F7 年代

  过热 → 放弃（除非有碾压级头部能力）

  ① 能连续写 100 万字不腻吗？（D11）

  ③ 读者点开想获得哪种情绪？（D1/D13）
```

## 五、六大情绪刚需

| 刚需 | 读者想要的 | 典型赛道 | 爆款机制 |
|---|---|---|---|
| **爽** | 憋屈释放、打脸成功 | 高武、战神、脑洞 | 压迫→蓄力→爆发 |
| **甜** | 被偏爱、被坚定选择 | 豪门、甜宠 | 反差呵护 + 独占性 |
| **悬** | 悬念揭开、逻辑验证 | 悬疑、规则怪谈 | 谜面→线索→反转→揭底 |
| **燃** | 明知不可为而为之 | 玄幻、历史 | 绝境 + 信念 + 代价 |
| **猎奇** | 看到从没见过的东西 | 都市脑洞、兽世 | 设定反差 + 快速具象 |
| **优越感** | 我比剧中人更聪明 | **专业流、智斗** | 信息差 + 降维 + 旁观者惊叹 |

**纪律**：主情绪最多 1 种，辅情绪最多 1 种。错配（男频写治愈、女频写硬核权谋）→ D1 ≤ 3。

## 六、代入感四支柱

| 支柱 | 机制 | 反例 |
|---|---|---|
| 1. 即时处境清晰 | 前 300 字知道他在哪、被谁逼 | 开篇写世界观、天气、家族史 |
| 2. 欲望可共情 | 主角想要的是普通人也想要的 | 「为了天下苍生」 |
| 3. 代价可感受 | 失败会失去具体的东西 | 只说「他很惨」 |
| 4. 主动性 | 主角在做选择，不是被推着走 | 全程被动挨打 |

**自检三问**：前 300 字知道主角现在最想要什么吗？失败会具体失去什么？第 1 章他主动做了选择吗？
任一答「否」→ 开篇重写。

## 八、情绪温度五档

| 档位 | 适用 | 每卷占比 |
|---|---|---|
| 冷 | 谷底、失去、回忆 | 10–15% |
| 温 | 过渡、日常、信息 | 20–25% |
| 热 | 打脸、对峙、揭秘 | 30–35% |
| 爆 | 爽感释放、反转 | 15–20% |
| 极爆 | 全书最高潮 | 5–10% |

**铁律**：不可连续 5 章同档；冷章后必须有热/爆跟进；憋屈连续 ≤ 2 章；极爆每卷 ≤ 2 次。

**张弛比**：全书约 3:1，爽文可偏 1.5:1。「张」不可连续超 2 章。
