# 文风基线 · 口语生活

> **赛道**：都市日常 / 轻松向 / 生活流
> **一句话**：允许长句、允许重复、允许废话，节奏松，口癖多。
> **定位**：用户指定「轻松」「日常」「生活流」，或赛道为都市日常时套用。

## 一、句法

- **允许长句**：平均句长 22–32 字，长句（35 字+）占比可到 30%。
- **允许重复**：「我跟你讲，是真的，真的。」「行行行，好好好。」
- **允许废话**：「然后呢，然后我就……哎算了不说了。」
- 呼吸节奏松，允许一句话分好几个逗号铺开。

## 二、段落

- 段落可长可短，不必刻意切碎。
- 允许整段都是闲扯——这类「废话段」每周至少一篇里能有 1–2 段。
- 不追求信息密度，追求「生活感」。

## 三、对话

- 口癖是核心：每个人物有自己的口头禅，反复出现。
- 允许答非所问、跑题、寒暄：
  例：「吃了吗？」「刚吃完，你呢？」「我还没吃，这不刚起。」「那你赶紧的。」
- 对话可以连着五六轮不推进剧情——这就是生活流的味道。

## 四、形容词与比喻

- 形容词可以多一点，但**要口语化**：「贼快」「老远」「整个一大无语」。
- 少用书面比喻，多用生活中的联想。

## 五、独有约束（相对其他基线）

| 项        | 口语生活        |
| -------- | ----------- |
| 平均句长     | 中长（22–32）   |
| 允许废话     | 大量          |
| 允许抒情     | 少量，且口语化     |
| 叙述者可插话   | 可以有         |
| 章末钩子     | 偏台词/画面      |

## 六、与硬规格的关系
