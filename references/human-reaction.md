# 人物反应真实性（人性的六条硬规则）

> 解决一个 `human-baseline.json` 覆盖不到的层面：
> 基线查的是「**句子分布**像不像人写的」（句长/段长/对话占比），
> 本文件查的是「**人**像不像人」——尤其是**群体反应**。
>
> 二者不能互替。分布全绿、人味为零的稿子，是当前 AI 初稿最常见的失败形态。

## 病灶：三化

AI 写人群，默认会犯三种错，合称「三化」。

| 病灶 | 表现 | 本质 |
|---|---|---|
| **同步化** | 全场哗然 / 鸦雀无声 / 所有人都愣住了 / 无人敢应 | 把群众当一个整体写，用一个动作替代全部人的反应 |
| **化学纯化** | 嘲笑的全是恶人，同情的一定站出来，恐惧的只会发抖 | 每个人只携带一种情绪，且浓度 100%，没有杂质 |
| **功能化** | 每个路人的存在只为衬托主角（笑他、惊他、怕他、捧他） | 群众是主角的镜子，不是有自己生活的人 |

三化的共同后果：**世界是布景，不是人间。** 读者不会说"假"，但会觉得"这书里的人都不太聪明，也不太像活的"。

## R1 群体必须分裂

**任何一次群体反应，至少拆出 3 种不同立场。** 立场数量不够，就先别写群众。

六种立场库（每次从中取 3 种以上）：

| 立场 | 行为特征 | 注意 |
|---|---|---|
| **领头者** | 第一个出声，有名有姓，只有 1–2 个 | 只有他敢大声，其他人是跟他的 |
| **跟风者** | 笑，但先看别人脸色；别人不笑就收住 | 写"半声笑"比写"哄笑"真 |
| **尴尬者** | 想缓和，结果是说错话，或说了一句没人接的话 | 最容易被写漏，也最像真人 |
| **回避者** | 假装忙自己的事：系鞋带、翻册子、看天 | 回避是多数人的真实选择 |
| **私语同情者** | 小声对身边人说，说完立刻补一句"反正不关我事" | 善良是有的，但很怯 |
| **无关者** | 完全没注意，在想自己的事（午饭、鞋、钱） | 每场至少放一个 |

**反例（同步化）**

> 广场上静了一秒，然后炸开。
> 「空白？」
> 「这什么情况，碑坏了？」
> 零信两个字一落地，笑声就压不住了。

问题：一秒之内全体完成"静→炸→笑"的转换，中间没有任何人掉队。这不是人群，这是一个声音。

**正例（分裂）**

> 前排先静下来，后面还在说话，有人探着脖子问前面在笑什么。
>
> 「空的。」有人回头，压着声音传，「碑上一个字都没有。」
>
> 「空的？」后头那人愣了愣，随即笑出声，「还有这种？我以为课本上瞎编的。」
>
> 他笑得挺响，笑到一半发现只有自己在笑，就收了，扭头看别人。
>
> 旁边一个女生把手里的册子合上，合得很轻，像怕被听见。
>
> 「你合它干什么。」她同伴小声问。
>
> 「没事。」她说，「就是觉得……别看了。」
>
> 队伍最后排，有人在系鞋带。系了三遍。

差别：正例里**没有人代表"群众"**，每个人都只有自己那一小块反应。恐惧不在"炸开"里，在"合册子的动作很轻"和"系了三遍鞋带"里。

## R2 情绪错位表达

**人几乎不说自己真实的情绪。** 说出来的是替代品。

| 真实情绪 | 常见的外显（错位） |
|---|---|
| 恐惧 | 发怒、挑刺、大声、开玩笑、突然讲规矩 |
| 羞耻 | 攻击对方、贬低对方的东西、强调自己不在乎 |
| 同情 | 移开视线、递个东西不说话、说"这不关我事" |
| 震惊 | 关心无关细节（"你鞋带开了"）、重复对方最后一句话 |
| 悲伤 | 去处理琐事（收碗、擦桌、扫地）、突然聊天气 |
| 心虚 | 过度解释、主动帮忙、话变多 |

**禁令**：台词不得直接命名自己的情绪。「我好怕」「我很同情你」「我很难过」——除非人物卡上登记了"此人不掩饰"，且全书一致。

**反例（化学纯化）**

> 「赵铁，」有人低声提醒，「别惹事。」

这句是对的（回避者），但接下来所有人都只剩两种反应：劝和 / 看热闹。缺的是**错位**。

**正例**

> 「赵铁，」有人低声说，「别。」
>
> 赵铁回头看了他一眼。
>
> 那人立刻改口：「我就是说……地上有血不好扫。」
>
> 说完自己也知道这话没道理，就别过脸去了。

那人真正想说的是"别打他"，但他不敢说，于是说了一句关于扫地的话。**这就是人。**

## R3 私域优先

人的注意力永远有一部分留在自己的小事上，哪怕天塌了。

**硬指标：每 300 字至少一处"私心噪声"**——与主线无关、纯粹属于某个人的私事。

素材库：

- 名额还剩几个、自己排第几
- 家里在等结果、爹娘交代过的话
- 待会儿的饭、饿了、口渴、憋着尿
- 暗恋的人在不在看、衣服是不是旧的
- 鞋不合脚、胳膊上有个包、昨晚没睡好
- 怕被记过影响分配、怕被叫家长
- 借了谁的钱还没还

**作用**：主角在承受命运的时候，旁边有人在想午饭。这才是人间。

**反例**

> 他听见了。他把这些人的脸，一张一张看过去。

主角在看所有人的脸——但所有人都在看他，没有一个人在过自己的生活。整个广场为他一人的命运暂停了。

**正例**

> 他听见了。
>
> 前面那个说"别看了"的女生，正在把册子往包里塞，塞了两次没塞进去，拉链卡住了。
>
> 后排系鞋带的人站起来，拍了拍膝盖，问他同伴：「食堂今天有红烧肉吗？」
>
> 「周三。」同伴说，「周三才有。」
>
> 「哦。」他有点失望。

这段里没有人安慰主角，也没有人继续嘲笑。**世界没有为他的命运停一下。** 这比任何同情都更冷，也更真实。

## R4 反应不齐、不即时

真人不是反应机。四种异步形态，每场至少用一种：

| 形态 | 写法 |
|---|---|
| **慢半拍** | 三秒后才笑，而且笑错了地方（该笑时没笑，不该笑时笑了） |
| **后置反应** | 当场没反应，回去才后怕（可挪到下一章开头，效果极好） |
| **反应错** | 该怕的时候笑，该笑的时候哭，该说话的时候清嗓子 |
| **全程无反应** | 从头到尾在走神，事后问"刚才怎么了" |

**同步词禁令**（写正文时不要出现，机器侧有 `crowd-sync-tic` 兜底）：

> 全场哗然 / 鸦雀无声 / 一片死寂 / 所有人都 / 无人敢 / 无一例外 / 齐刷刷 / 不约而同 / 众人皆 / 满座皆惊 / 人人大惊

替换方向：**指明是谁，写他做了什么，别写"大家"。**

## R5 施害者带自己的困境

反派、恶人、找茬的、霸凌的——**出手前，必须携带一个与主角无关的私人困境**，并在文本里露一次（不必解释）。

不是"给他洗白"，是"让他有重量"。纯恶人是纸片；有困境的恶人才让人恨得具体。

**反例**

> 「空白的，」赵铁啐了一口，「老子当年一拳上过榜的，最烦你们这种白占名额的。」

他为什么烦白占名额的？文本没给。他只是一个"嚣张的老生"。

**正例**

> 「空白的。」赵铁啐了一口。
>
> 他今天来得很早。天没亮就来了，站在队伍最前头，看着工人把碑吊正、把红布挂上。他今年第三次来。前两次都没轮上名额，家里已经不太问他了。
>
> 「最烦你们这种白占的。」

同一个动作，重量完全不同：他不是在羞辱一个废材，他是在护住自己快要没的东西。

**并且：施害者受伤后，第一反应不该是丢脸，是他自己的困惑。**

> 赵铁低头看自己的手。血在滴。
>
> 他先想到的不是疼。
>
> 是「我刚才那一拳，用的到底是几分力」。
>
> 他想不起来了。

## R6 群体反应从身体出发，不从判断出发

**禁止**：作者替群众下判断。

> 大家都用看怪物的眼神看他 / 众人心里发毛 / 所有人都觉得他不祥 / 气氛变得诡异

**允许**：一个具体的人，一个具体的动作，一个不合时宜的顾虑。

> 前排女生把册子合上，合得很轻，像怕被听见。
>
> 有人往后退，退到一半停住了——后面也是人，退不动。
>
> 「你踩我脚了。」
>
> 「哦，对不住。」

**原理**：恐惧不写在脸上，写在**身体先做了一件不必要的事**上。合册子不必那么轻，系鞋带不必系三遍，退半步也不必道歉——这些多余的动作，才是恐惧的形状。

## 写完自查（五问，进第十一节人工审稿）

1. 这一场里，有几个人是「**有名有姓 + 有自己的事**」的？（至少 1 个）
2. 群体反应能不能拆成 **3 种以上立场**？
3. 有没有一句台词**直接说出了人物的真实情绪**？（有则改写为错位表达）
4. 有没有一处「**与主线无关的私心**」？
5. 主角承受大事时，旁边有没有人**在想小事**？

五问全「是」才可交付。机器不判这五问——`crowd-sync-tic` 只抓同步词密度，抓不到"分裂是否成立"。
