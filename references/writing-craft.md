# 写作约束全表（正向 + 禁止）

> 本文件是 SKILL.md 第七节的下沉版：写正文前读一遍，写完对着自查。
> 分层原则不变——这些全是 **advisory / 人工审稿项**，不进 `spec_check.py` 退出码；
> 唯一例外是「禁止词 / 禁止句式 / 禁止结构」里的硬禁项，它们在 lint 层是 blocking。
> 为什么拆出来：常驻层只留判断问句，细则按需读，别让 2 万字正文陪 3 万字规则跑。

## 一、正向写作约束（不是配额，是写完要问自己的句子）

禁止清单只能清零机械感，不能产生人味。以下每条都写成诊断问句：**答「没有」就补一处，不为凑数补。**

1. **这一章有闲笔吗？** 不推进主线、不服务爽点、不埋伏笔的那一小段——一段天气、一个路人、一次走神、一句无关的对话。
2. **这一章有一句「删了不影响剧情」的对话吗？** 寒暄、跑题、口癖、答非所问、重复。抽一遍本章对话，若每句都在推动剧情，回补一句。
3. **这一章的句子有起伏吗？** 连续 5 句以上短句后，可以有一个长句；连续 3 个长句后，可以砸一个短句。**不要为了达标去合并句子**——人机句长离散度实测无差异（`rejected-signals.md` X-8），写成「40 字以上 ≥10%」只会让模型凑数。只查极端：整章一个长句都没有 → 回看铺陈、闪回、场景过渡处是不是被拆碎了。人类基线 p90=53 是**参照**，不是目标线。
4. **这一章有没有一点「不完美」？** 一个突然的比喻、一个没回收的细节、一个和主线无关的闪回。这是人类写作的自然噪声，不是缺点，别清理得太干净。
5. **上一章是不是也是强钩子？** 强钩子连着用会钝。允许某一章停在一个画面、一句台词、一个动作上。
6. **对话连续超过 5 轮没插动作吗？** 超过就插一个动作或环境。
7. **这一章有「本来可以拆成三段但选择不拆」的那一段吗？** 环境铺陈、心理闪回、场景过渡都是自然落点，长度 91–120 字，全章只许一段（走 `spec_check.py` 的豁免带；第 2 段起与 >120 字判 blocking）。全章都是 30 字以内短段，分布上会显得过于均匀（人类基线段长 p90=66.5 / p99=107.8）。
8. **这一场里有没有一个可核查的具体物？** 数字、价格、时间点、物件名、专名。五感管「感觉像真的」，具体物管「颗粒度像真的」——「豪华的办公室」是形容，「报价单停在 47 万那一行」才是场景。抽象表述扎堆的段落，优先换具体物，不换形容词。

> 分布级检测见 `scripts/check-distribution.py`（句长/段长分布、长句/长段存在性、对话波动/信息密度/伏笔间隔，全部 advisory）；
> 跨章多样性（含对话风格）见 `scripts/check-cross-diversity.py`。
> 这两个脚本是「查分布」而非「查词」——AI 指纹不在用了哪个词，在整段文本的统计分布像不像人写的。

## 二、人性刚性六条（人群、情绪、私域）

> 上面管**文笔**，分布检测管**形状**。这一组管**人**。
> 分布全绿但人物像布景的稿子，是本 skill 目前最大的漏检面。
> 完整规范 + 正反例见 `human-reaction.md`，**写人群场景前必读**。

| # | 规则 | 自查口径 |
|---|---|---|
| **H1** | **群体必须分裂** | 一次群体反应 ≥3 种立场（领头/跟风/尴尬/回避/私语同情/无关），且不写"所有人" |
| **H2** | **情绪错位表达** | 台词不得直接命名自己的情绪（"我好怕""我很同情你"）；恐惧写发怒，同情写移开视线 |
| **H3** | **私域优先** | 每 300 字 ≥1 处与主线无关的私心（名额、饭、鞋、钱、暗恋）；主角承受大事时，旁边有人在想小事 |
| **H4** | **反应不齐、不即时** | 每场 ≥1 种异步（慢半拍/后置/反应错/走神）；**禁同步词**：全场哗然、鸦雀无声、所有人都、无人敢、齐刷刷、不约而同 |
| **H5** | **施害者带自己的困境** | 反派出手前，携带一个与主角无关的私人困境，并露一次（不解释、不洗白） |
| **H6** | **从身体出发，不从判断出发** | 禁"大家都用看怪物的眼神看他"；允"她合册子合得很轻，像怕被听见" |

**常见失败形态（三化）**：同步化（一团人一个反应）、化学纯化（一人一情绪浓度 100%）、功能化（路人只为衬托主角）。
三者任一成立，场景即判「有人在演，没人在活」。

## 三、结构刚性三条（场景骨架）

> 六条管**人**，这三条管**事**。人和事都对，章节才立得住。
> 完整规范 + 网文四类场（战斗/对峙/交易/爽点）的灾难形态见 `scene-architecture.md`。

| # | 规则 | 自查口径 |
|---|---|---|
| **S1** | **目标必须能拍照** | 这一场他要拿到什么，一句话，具体到物件或某句话；"他要变强""他要活下去"不算本场目标 |
| **S2** | **灾难不许是完胜** | 每场结尾只能是「不给」或「给了但更糟」；爽点场的完胜必须占三例外之一（付了代价／引出更大麻烦／身边人重新评估他） |
| **S3** | **接缝只许「因此／但是」** | 相邻场景用「然后」才连得上＝结构散了；一章出现 2 处以上，重排顺序 |

## 四、镜头一条（叙述距离）

> 灾难落下的那一段，**叙述距离必须升到第 4–5 档**。整章停在第 3 档直陈情绪（"他心里一沉""一股无力感涌上来"）＝读者知道出事了，但不会疼。
> 五档定义、四标记判档法、过滤器动词的删法见 `narrative-distance.md`。

## 五、禁止清单（写正文时就避开，不必等 lint 报）

> 负面清单比正面描述管用十倍。每条都有机器规则兜底，违反会被 `check-ai-patterns.js` 判为 blocking。

### 5.1 禁止词

**硬禁（出现即判 blocking，机器必拦）**

判据是**位置 + 词族**，不是一张禁用词表——同族里换任何一个词，判罚相同。

| 类别 | 判据（位置 × 词族） | 机检规则 |
| ----- | ------------------ | -------- |
| 突变起跳 | **段首/分句首**的「忽然/突然/蓦然/猛然/骤然/霍然/倏然/陡然/猛地/腾地/冷不丁」。句中的「他忽然想起那年冬天」放行 | `hard-banned-word` |
| 情绪直述（副词型） | 程度副词（非常/十分/极其/极为/无比/格外/特别/异常/分外/极度/相当/太）**紧接情绪形容词**（生气/意外/紧张/害怕/满意/失望…）。「非常时期」「十分之一」「不太高兴」放行 | `hard-banned-word` |
| 情绪直述（动词型） | 很＋情绪形容词、内心充满/涌起/一片、感到愤怒/悲伤/恐惧、恍惚 | `hard-banned-word` |
| 章尾预告词 | 正朝着、压了过去、才刚刚开始、没人知道、没有人知道、谁也不知道 | `trailer-ending` |
| 工程引用 | 第 5 章、第十一章、上一章、本章、本卷（章号指代情节） | `hard-banned-word` |

> **换同义词不算改**：旧版只禁「忽然」不禁「突然」、只禁「非常」不禁「特别」，
> 两句话语义、节奏、画面完全相同，门禁却把 a 判死、把 b 判活。结果是模型学到
> 「忽然→突然」的替换表，而不是「用动作起跳」——门禁在奖励更假的文字。
> 现在整族按位置判，改写必须落到**动作、物件或后果**上（原理见 `pitfalls.md` P28）。

> 硬禁词只扫**引号外叙述层**——台词里的「你非常生气」是人物口语，不算叙述腔。
> 量词用法（只剩十分钟、十分之一）与否定式（不太高兴、不十分满意）不在判据位置内，自动放行。
> **工程引用豁免文内合法分章**：故事世界里真有书/法典/碑文分章时不算残留——
> `他翻开《指南》第九章`、`法典第十一章：不可妄言` 里若前置有《》书名号、引号占位或
> 「卷/册/篇/回/书/典/经/谱/志/录/集/碑/文」载体词，则跳过。真残留（`第 5 章在食堂`）
> 都出现在句子中段、无上述语境，照报不误。半角数字+空格形态也认。

**密度约束（不硬禁，但聚集即报 advisory，须逐条判断）**

| 类别 | 词 | 阈值 |
| ----- | ---------------- | -------------------------- |
| 比喻标记 | 好像、像是、仿佛、宛如、如同、犹如 | **同段 ≥3 个** → advisory（不按全章密度判） |
| 高危套词 | 一丝、一抹、深吸一口气、眼中闪过、平静无波 | ≥8 处且 ≥12/千字 → advisory |

> **比喻按「同段成片」判，不按「全章密度」判**：配对复测显示人类比喻标记是 AI 的
> 2.4 倍（0.38 vs 0.16/千字）——按全章密度判等于惩罚爱用比喻的作者。真正的 AI 味是
> 「一段里连着比三下」。删的时候**不要同义词轮换**，改成具体动作、物件或后果。
> 详见 `rejected-signals.md` X-7。

### 5.2 禁止句式（命中即 blocking）

| 型号 | 形态 | 改法 |
| ------------------- | ------------------- | ------------------------- |
| `not-is-comparison` | 「不是A，而是B」 | 删否定铺垫，直接写后项；或改成动作呈现 |
| `reverse-not-is` | 「是A，不是B」 | 删后置否定，直接写 A 的表现 |
| `voice-contrast` | 「声音不大…却…」 | 删音量铺垫，写声音落进现场的具体效果 |
| `negation-parade` | 「没有X，没有Y」/「没X没Y只是Z」 | 删否定清单，直接写现场实际有什么 |
| `em-dash`（条件） | 破折号 `——`（引号内不算） | 打断→动作 beat；拖长音→省略；插入说明→逗号 |
| `trailer-ending` | 「正朝着…压了过去」 | 结尾停在具体动作、画面或台词上 |
| `trailer-summary` | 「这一夜注定…」「命运的齿轮」 | 结尾用最后一个具体动作落地，不替读者盖章 |

### 5.3 禁止结构

**硬禁（blocking）**

- 章末收在「事情办完了」「然后他睡着了」——蔡格尼克效应，悬念消失即掉追更
- 章末套话：「欲知后事如何，且听下回分解」/「这一夜，无人入眠」/「命运的齿轮，开始转动」/「未完待续」

**写作约束（无对应 blocking 规则，靠自律）**

- 单段超过 90 字（`spec_check.py` 豁免带只给 1 段、上限 120 字；手机屏约 3–4 行）
- 对话连续超过 5 轮不插动作或环境（读起来全是引号，节奏碎）
- 连续三段以「他」「她」开头

**密度型（advisory，读上下文判断）**

| 情形 | 规则型号 | 处置 |
| ---------------- | ---------------- | ------------------ |
| 叙述层用 1–4 字引号做强调 | `quote-emphasis` | 只留反讽/转述必要的，其余去引号 |
| 同段摆 5 个以上动作动词 | `action-list` | 合并琐碎步骤；打斗编排可保留 |
