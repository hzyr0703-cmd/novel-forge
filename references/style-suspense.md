# 文风基线 · 悬疑紧张

> **赛道**：悬疑 / 无限流 / 规则怪谈 / 惊悚
> **一句话**：句长交替明显，长句铺陈，短句砸点，留白多，对话少。
> **定位**：赛道为悬疑/无限流，或用户指定「紧张」「压抑」时套用。

## 一、句法

- **句长交替明显**：这是核心。长篇铺陈（40–60 字）后紧跟一个极短句（3–6 字）砸点。
  例：「走廊尽头的灯一盏一盏地灭下去，像是有人在按着顺序拧灭它们。他停住了。」
- 长句用于铺陈环境和心理压力，短句用于突发和定论。
- 允许不完整句：「脚步声。」「越来越近。」

## 二、段落

- 段落偏短，营造窒息感。
- **大量留白**：单句成段，甚至单字成段（「门。」）。
- 一章内允许 2–3 处「极短段」制造停顿。

## 三、对话

- **对话少**：悬疑向的张力来自「没说出口的」，对话占比常在 20% 以下。
- 对话短、断裂，答非所问是常态：
  例：「你听见了吗？」「……」「你也听见了。」
- 沉默本身就是内容。

## 四、形容词与比喻

- 形容词克制，但比喻可以**冷、怪、具体**。
- 不要「恐怖」「可怕」这类直述，用身体反应和环境细节代替。
  例：不写「他感到非常恐怖」，写「他发现自己不敢回头看第二眼」。

## 五、独有约束（相对其他基线）

| 项        | 悬疑紧张        |
| -------- | ----------- |
| 平均句长     | 两极分化（长+极短）  |
| 允许废话     | 几乎不         |
| 允许抒情     | 极少          |
| 留白       | 多（单句/单字段）   |
| 章末钩子     | 偏悬念/画面      |

## 六、与硬规格的关系
