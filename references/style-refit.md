# 文笔回改手册（style-refit）

> 适用时刻：分布检测（`check-distribution.py`）显示句长 sd 明显低于人类基线（<13，基线 21.7）、
> 整章一个 40 字以上长句都没有、或全书/整卷一个呼吸节奏时。这是**改稿手法**，不是写作约束——
> 写新章时直接按第七节正向约束落笔，不需要走本流程；本手册用于**已提交章的批量回改**。
> 实证来源：《燃识》第 39 章试点 + 13–41 全区间 29 章推广收口（2026-10-13 终验
> sd 全线 ≥13、crossrepeat/factconflicts 双 OK，见下）。

## 一、核心手法：删复述就是补长句

不要"加长句"，那会注水。正确动作是**把已有的短句用标点接起来**，把讲同一件事的
段落并成一个，结论并进长句。四类动作按序执行：

| # | 动作 | 说明 | 优先级 |
|---|---|---|---|
| 1 | **删复述段** | 同一意思出现 2–3 段的，留最具体的一段，其余删；结论句并进保留段的末尾 | 主要动作，先做 |
| 2 | **短句黏合** | 用冒号/分号/逗号把 2–4 个讲同一件事的短句接成 1 个长句（40–85 字），不新增信息 | 每章 10–15 处 |
| 3 | **修硬伤** | 孤段（单字/短语成段的"二十。""差一个。"）并入上下文；重复合并；问答断裂修复 | 顺手做 |
| 4 | **补质感** | 删复述腾出字数余量后，补**非复述**内容：环境小物、人物声口、无关动作 | 只在字数有余量时做 |

**保留不动**：跨章 motif（如某句在多章复现是刻意的钩子）、p50 附近的短句底色、
对话层、单字成段里的**有意**节拍（每章留 1–2 个，全删会失去顿挫）。

## 二、操作顺序（每章固定流程）

```
1. 备份：cp 正文/final/第N章-*.md .story/work/第N章/pilot/before-final.md
2. spec_check 记录改前字数 —— 若距 3200 上限 <100 字，本轮只删不加（见坑 R1）
3. check-distribution 记录改前基线（sd / 长句% / p50 / 对话率）
4. 通读一遍，标出复述段与黏合候选
5. 按四类动作改 final 层
6. 收尾归一：连续空行压成单空行（编辑器删段必留 \n\n\n，见坑 R3）
7. 验收（下节），不过回改，过则 cp final → draft 同步两层
8. forge.py export 重建导出层
```

## 三、验收线（全过才算改完）

| 指标 | 线 | 工具 |
|---|---|---|
| 句长 sd | ≥13（试点实测 15.4–17.5） | check-distribution |
| 40 字以上长句 | 存在且句式不重复（不设占比） | 同上 |
| p50 中位句长 | **不动**（±2 内）——短句底色是赛道对的东西，只补长尾 | 同上 |
| 对话率 | 不降 | 同上 |
| spec_check | blocking 0（advisory 逐条判断） | spec_check |
| 字数 | 门禁带内（1800–3200），欠字不加戏 | spec_check |
| 人工通读 | 情节零变化、无新 AI 腔 | 人 |

## 四、坑位（实证）

**R1 · 顶字数上限的章先删再加。** 改前字数距 3200 不足 100 字时，先靠删复述腾余量，
再决定补多少质感。《燃识》ch36 改前 3147，先加后删一度爆到 3272 blocking，返工一轮。

**R2 · 黏合段受 90 字段长上限约束。** 长句可以长，但**段落**超 90 字是 blocking。
一个 85 字长句单独成段没问题；两句 60 字长句同段就爆。黏合完逐段看长度，
超了就按句拆回两段——拆段不破坏长句，sd 不受损。

**R3 · 编辑器删段必留连续空行。** 删掉一整段后上下会剩 `\n\n\n`，导致导出层与
final 层比对出现"幽灵空行差异"。每章改完统一把 `\n{3,}` 压成 `\n\n`。

**R4 · 分号是长句的主力，破折号是禁区。** 黏合用「：」「；」「，」；`——` 是
硬禁句式，黏合时最容易顺手写出来。

**R5 · 每章改动控制在 15–25 处编辑。** 超过这个量说明这章该整体重写而不是回改，
停下来评估是否走重写保护流程（见 plot-recovery.md）。

**R6 · 只动叙述层，不动对话。** 对话是角色声口，黏合对话会杀人味；对话率偏低
是另一个问题（补对话/把描写改交互），不要在回改里顺手改台词。

**R7 · 黏合会系统性抬 p50。** 每次黏合消灭 2 个短句、新增 1 个长句，p50 必然上移；
p50 ≥15 的章黏完常超 ±2 线（ch27 曾 +3 超差）。决策树：改前先看 p50——
p50=12 碎句型可全面黏合；p50 ≥15 的章**只拼大句**（长句并长句），跳过小黏合；
对话率 >25% 的章叙述层句子基数小，要更大胆的跨句合并才能凑线。回退手法：
超差时挑 1–2 处小黏合恢复成原短句节拍（「人散了。」这类），p50 即回落。

**R8 · 零余量章（余量 <300）的三种凑线手法。** ①纯黏合零加字：只改标点，
sd 可从 9–11 拉到 13+，最稳；②**尾句延展**：在段尾既有句上延展几字（如
「谁也没让他停下脚步」「最后一点声也没了」），不新增段落不新信息，差 0.2–0.5
时用；③p50 保持术：把两个短句合并的位置放在「本来就长」的句子旁边，短句
节拍点（单字成段、三字句）一律不碰。

**R9 · 对话插话会往下拽 p50（候选）。** 拆独白补交互时，每插一组问答就多 2 个
短句，p50 随之下移；ch14 实测连插 6 组后 p50 12→10，已到 -2 贴线。单章对话
插话量估 6–8 组封顶，插完必验 p50；要拉全书中位对话率，只能多章分摊，
不能单章硬灌。插话内容铁律：只做既有事实的回声（复述/追问/短应答），
零新设定零新信息。

**R10 · 人物到来开场撞型 + 分类器 [DRAFT] 盲区（2026-10-13 实证）。**
两个坑一起踩出来的：

坑 A · 开场「同人物到来」指纹。当某人物是主角的固定情报入口（送消息/递
名单/报信），每章新冲突都靠他上门引爆时，会连续多章以「X 来了 / X 敲门的
时候 / X 又来」开局——燃识 ch23–28 实证连续 6 章、其中 4 章首句主语都是
陈冬。读者一眼看出「又是他来敲门」。修法（零剧情改动）：① 保留 1–2 章
人物开场，其余换型——环境先行（先写脚步声/楼梯动静，人后进场）、对白砸开
（台词第一，人后自明）；② 复读意象必须拆：同一细节（如「敲两下停一下」
「压低声音」）禁止在 3 章内出现 2 次。

坑 B · 分类器首段被状态标记污染。章文件头部的 `[DRAFT]` 行会被
prose_paragraphs 当成首段拿去归类（有的文件 `[DRAFT]` 行尾带 markdown 硬
换行空格，还会和正文首段粘成一段），导致开头分类几乎全落「其他」，对话/
环境开场全部漏判，多样性检测输出假绿。已在 check-cross-diversity.py 修复
（按行剔除 `[DRAFT]/[FINAL]` 标记），并新增 8.6 人物到来开场检测：滑动
5 章窗口内同一人物到来式开场 ≥3 次即 advisory。

回改检验顺序：改开场前先跑 check-cross-diversity 看开头行真实分布，确认
没有 `[DRAFT]` 污染（若满屏「其他」先修分类器再动正文，否则改了也看不见
效果）。

**R10 附 · 同批排查出的已知限制（2026-10-13）**

- **meta 覆盖链**：cross-diversity 的开头/结尾分类优先读 `meta/第N章.json`
  的 `opening_type/ending_type`，只有缺省才走文本推断。燃识的 meta 没有这两
  个键所以安全；未来若往 meta 写入这两个字段，文本推断会静默失效——写入前
  先确认标注准确，或干脆不写、让文本推断兜底。
- **distribution 同款 [DRAFT] 污染已修**：strip_markdown_scaffold 原来不滤
  状态标记行，`[DRAFT]` 会混进句长统计（行尾硬换行时还会粘住首句）。已修，
  与 cross-diversity 同款修法。**以后新脚本凡做「取正文首段/首句」操作的，
  一律先剔状态标记行**——这是 skill 级公约。
- **arrival 正则盲区（已收窄）**：认「X 来/X 又来/X 敲门/X 进门/X 送到/是…来的
  /X 把门推开/X 闪进来/X 挤进来/X 探头」句式 + 2–3 字人名（懒惰量词）；复合
  姓/四字名仍不覆盖。漏报可接受（advisory 不阻断），别指望它抓全。
- **结尾「其他」半误报（已解决）**：新增「节拍」结尾类别——超短末段（去空白
  ≤12 字）且不含任何词表词的收束句（「老祝没回来。」「蹭不掉。」）单列，不再
  落「其他」。41 章回归：6 章正确改判，结尾分布真实化。若未来出现「节拍」
  连续 3 章的 advisory，先看是不是真的一味用单句顿收。

## 五、推广节奏

按"往后章节当样板"优先：先改最新章节（往后几十章都按这个手感写），验收通过后
再往回推。每批 5 章左右，批内逐章独立验收，不批量化处理（每章的复述位置不同）。
