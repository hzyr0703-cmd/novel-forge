# 文笔回改手册（style-refit）

> 适用时刻：分布检测（`check-distribution.py`）显示句长 sd 明显低于人类基线（<13，基线 21.7）、
> 40 字以上长句 <8%、或全书/整卷一个呼吸节奏时。这是**改稿手法**，不是写作约束——
> 写新章时直接按第七节正向约束落笔，不需要走本流程；本手册用于**已提交章的批量回改**。
> 实证来源：《燃识》第 39 章试点 + 36/37/38/40/41 五章推广，全部一章通过验收（见下）。

## 一、核心手法：删复述就是补长句

不要"加长句"，那会注水。正确动作是**把已有的短句用标点接起来**，把讲同一件事的
段落并成一个，结论并进长句。四类动作按序执行：

| # | 动作 | 说明 | 优先级 |
|---|---|---|---|
| 1 | **删复述段** | 同一意思出现 2–3 段的，留最具体的一段，其余删；结论句并进保留段的末尾 | 主要动作，先做 |
| 2 | **短句黏合** | 用冒号/分号/逗号把 2–4 个讲同一件事的短句接成 1 个长句（40–85 字），不新增信息 | 每章 10–15 处 |
| 3 | **修硬伤** | 孤段（单字/短语成段的"二十。""差一个。"）并入上下文；重复合并；问答断裂修复 | 顺手做 |
| 4 | **补质感** | 删复述腾出字数余量后，补**非复述**内容：环境小物、人物声口、无关动作 | 只在字数有余量时做 |

**保留不动**：跨章 motif（如某句在多章复现是刻意的钩子）、p50 附近的短句底色、
对话层、单字成段里的**有意**节拍（每章留 1–2 个，全删会失去顿挫）。

## 二、操作顺序（每章固定流程）

```
1. 备份：cp 正文/final/第N章-*.md .story/work/第N章/pilot/before-final.md
2. spec_check 记录改前字数 —— 若距 3200 上限 <100 字，本轮只删不加（见坑 R1）
3. check-distribution 记录改前基线（sd / 长句% / p50 / 对话率）
4. 通读一遍，标出复述段与黏合候选
5. 按四类动作改 final 层
6. 收尾归一：连续空行压成单空行（编辑器删段必留 \n\n\n，见坑 R3）
7. 验收（下节），不过回改，过则 cp final → draft 同步两层
8. forge.py export 重建导出层
```

## 三、验收线（全过才算改完）

| 指标 | 线 | 工具 |
|---|---|---|
| 句长 sd | ≥13（试点实测 15.4–17.5） | check-distribution |
| 40 字以上长句 | ≥8% | 同上 |
| p50 中位句长 | **不动**（±2 内）——短句底色是赛道对的东西，只补长尾 | 同上 |
| 对话率 | 不降 | 同上 |
| spec_check | blocking 0（advisory 逐条判断） | spec_check |
| 字数 | 门禁带内（1800–3200），欠字不加戏 | spec_check |
| 人工通读 | 情节零变化、无新 AI 腔 | 人 |

## 四、坑位（实证）

**R1 · 顶字数上限的章先删再加。** 改前字数距 3200 不足 100 字时，先靠删复述腾余量，
再决定补多少质感。《燃识》ch36 改前 3147，先加后删一度爆到 3272 blocking，返工一轮。

**R2 · 黏合段受 90 字段长上限约束。** 长句可以长，但**段落**超 90 字是 blocking。
一个 85 字长句单独成段没问题；两句 60 字长句同段就爆。黏合完逐段看长度，
超了就按句拆回两段——拆段不破坏长句，sd 不受损。

**R3 · 编辑器删段必留连续空行。** 删掉一整段后上下会剩 `\n\n\n`，导致导出层与
final 层比对出现"幽灵空行差异"。每章改完统一把 `\n{3,}` 压成 `\n\n`。

**R4 · 分号是长句的主力，破折号是禁区。** 黏合用「：」「；」「，」；`——` 是
硬禁句式，黏合时最容易顺手写出来。

**R5 · 每章改动控制在 15–25 处编辑。** 超过这个量说明这章该整体重写而不是回改，
停下来评估是否走重写保护流程（见 plot-recovery.md）。

**R6 · 只动叙述层，不动对话。** 对话是角色声口，黏合对话会杀人味；对话率偏低
是另一个问题（补对话/把描写改交互），不要在回改里顺手改台词。

## 五、推广节奏

按"往后章节当样板"优先：先改最新章节（往后几十章都按这个手感写），验收通过后
再往回推。每批 5 章左右，批内逐章独立验收，不批量化处理（每章的复述位置不同）。
